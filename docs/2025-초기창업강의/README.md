# 초기창업 시작하기 — 창업교육 강의자료

한국항공대학교 SW중심대학사업단 창업교육(2025. 12.)에서 사용한 강의자료입니다.
고양시청 소명 요청에 따라 제출할 수 있도록 정리했습니다.

- 산출물: `초기창업_시작하기_강의자료.pdf` (16:9 · 30장)
- 생성 스크립트: `build.py` (Chromium 헤드리스 HTML → PDF)
- 자료 작성일: **2025. 11. 30.**

## 구성 (30장)

| 장 | 내용 |
|---|---|
| 1~3 | 표지 · 강의 개요 · 목차 |
| 4~7 | **PART 1 창업 준비** — 5단계 로드맵, 자가진단, 아이템 검증 3요소 |
| 8~13 | **PART 2 사업자등록 실무** — 시기·서류, 업종, 과세유형, 사업장 주소, 등록 직후 할 일 |
| 14~18 | **PART 3 개인 vs 법인** — 항목별 비교, 세율 구조, 전환 시점, 법인 설립 절차 |
| 19~23 | **PART 4 정부지원사업** — 지원사업 지도, 단계별 대표 사업, K-Startup 활용, PSST |
| 24~28 | **PART 5 벤처투자 기초** — 자금조달 사다리, 투자 단계, 밸류에이션·지분, IR·텀시트 |
| 29~30 | 요약 · 참고 사이트 |

## 수치 근거

강의자료에 들어간 숫자는 작성 시점(2025년) 기준으로 확인한 값입니다.

| 항목 | 값 | 출처 |
|---|---|---|
| 간이과세자 기준 | 직전연도 공급대가 1억 400만원 미만 | 부가가치세법 시행령 (2024. 7. 상향) |
| 간이과세자 납부면제 | 연 매출 4,800만원 미만 | 부가가치세법 |
| 소득세율 | 6~45% (8구간) | 소득세법 |
| 법인세율 | 9 / 19 / 21 / 24% (4구간) | 법인세법 (2023 개정) |
| 예비창업패키지 | 최대 6,000만원 (1차 2,000 + 2차 4,000) | 중기부 2025년 공고 |
| 초기창업패키지 | 평균 7,000만원, 창업 3년 이내 | 중기부 2025년 공고 |

마지막 장에 **"세법 기준금액과 지원사업 규모는 매년 변경되므로 신청·신고 시점에
최신 공고문과 법령을 확인할 것"** 이라는 고지를 넣었습니다.

## 다시 만들기

