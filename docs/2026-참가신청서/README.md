## 만드는 법

1. **ces@rebornmarket.org 계정으로** [script.google.com](https://script.google.com) 접속 → **새 프로젝트**
2. `구글폼_생성.gs` 내용을 전부 붙여넣기 (기존 `myFunction` 은 지우고)
3. 상단 함수 선택창에서 **`createForm`** 선택 → **실행**
4. 첫 실행 때 권한 승인 창이 뜹니다. **고급 → 안전하지 않은 페이지로 이동 → 허용**
   (내 계정으로 내 드라이브에 폼을 만드는 것이라 정상입니다)
5. 실행 로그에 **편집 URL · 응답 URL · 응답 시트 URL** 이 찍힙니다

실행하면 6개 장, 21개 문항, 개인정보 동의문, 제출 완료 메시지, 응답 스프레드시트
연결까지 한 번에 만들어집니다.

## 딱 하나, 손으로 해야 하는 것 — 파일 업로드 문항

**사업계획서 첨부 문항은 스크립트로 만들 수 없습니다.** Apps Script 의 `FormApp`
에는 `addFileUploadItem()` 메서드 자체가 없어서, 다른 문항은 다 만들어져도 이것만
편집 화면에서 직접 추가해야 합니다. 30초면 됩니다.

1. 편집 URL 을 열고 **4장 「사업계획서 제출」** 로 이동
2. `⬇⬇ [편집자 확인] …` 이라고 적힌 안내 블록 자리에 질문 추가 (＋ 버튼)
3. 아래대로 설정

   | 항목 | 값 |
   |---|---|
   | 질문 | 사업계획서 파일 |
   | 유형 | **파일 업로드** |
   | 설명 | PDF · 한글(HWP) · 워드(DOCX) 중 택1 / 20MB 이내 |
   | 특정 파일 형식 허용 | PDF, 문서 |
   | 최대 파일 수 | 1 |
   | 최대 파일 크기 | 100MB |
   | 필수 질문 | 켜기 |

4. 다 하고 나면 `[편집자 확인]` 안내 블록은 **삭제**

## 파일 업로드를 쓸 때 미리 아셔야 할 것

- **응답자는 Google 계정 로그인이 필수**입니다. 파일 업로드 문항이 하나라도
  있으면 구글이 강제합니다. 로그인 없는 익명 접수는 불가능합니다.
- 업로드된 파일은 **폼 소유자(ces@rebornmarket.org)의 구글 드라이브**에 쌓이고
  **소유자의 저장 용량을 차지**합니다. 20MB × 수십 팀이면 얼마 안 되지만,
  드라이브 여유 용량은 미리 확인해 두세요.
- **Workspace(회사 도메인) 계정으로 만들면** 기본값이 "조직 내 사용자만"으로
  잡혀 학생들이 제출하지 못할 수 있습니다. 폼 **설정 → 응답 → 응답자 제한**에서
  조직 외부 응답을 허용해 두시고, 만들고 나서 **다른 브라우저(시크릿 창)에서
  반드시 한 번 테스트 제출**해 보세요. 이게 가장 흔한 사고 지점입니다.
- 위 두 가지가 걸리면 **메일 제출을 병행**하는 게 안전합니다. 폼 안내문에
  이미 "업로드가 계속 안 되면 ces@rebornmarket.org 로 메일 제출해도 접수된다"고
  적어 두었습니다.
