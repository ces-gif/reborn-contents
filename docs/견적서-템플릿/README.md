# 경영컨설팅 견적서 템플릿

- 산출물: `견적서_템플릿_경영컨설팅.xlsx` (3시트)
- 생성 스크립트: `build.py` (openpyxl)

## 시트 구성

| 시트 | 역할 |
|---|---|
| **견적서** | 인쇄용 본문. A4 세로 · 가로 1페이지 맞춤 · 눈금선 숨김 |
| **단가표** | 서비스 품목 마스터. 견적서 드롭다운의 원본 |
| 안내 | 사용법 |

## 수식 연결

```
단가표(품목·단위·단가)  →  견적서 C열 드롭다운 선택
                            ↓ VLOOKUP / INDEX+MATCH
                      구분 · 단위 · 단가 자동 입력
                            ↓
                   공급가액 = 수량 × 단가
                            ↓ SUM
            소계 → (−할인) → 공급가액 → (+부가세 10%) → 합계
                            ↓
                  상단 「합계금액」 한글 표기
```

| 셀 | 수식 |
|---|---|
| 구분 (B24) | `=IFERROR(INDEX(단가표!$A:$A,MATCH($C24,단가표!$B:$B,0)),"")` |
| 단위 (E24) | `=IFERROR(VLOOKUP($C24,단가표!$B:$D,2,0),"")` |
| 단가 (G24) | `=IFERROR(VLOOKUP($C24,단가표!$B:$D,3,0),"")` |
| 공급가액 (H24) | `=IF($C24="","",IFERROR(ROUND($F24*$G24,0),""))` |
| 소계 (H42) | `=SUM($H$24:$H$41)` |
| 공급가액 (H44) | `=$H$42-$H$43` |
| 부가세 (H45) | `=ROUND($H$44*0.1,0)` |
| 합계 (H46) | `=$H$44+$H$45` |
| 합계금액 한글 (C16) | `="금 "&TEXT($H$46,"#,##0")&"원정   (부가세 포함)"` |
| 견적번호 (H4) | `=TEXT($H$5,"yyyymmdd")&"-01"` |
| 유효기간 (H6) | `=$H$5+30` |

## 직접 입력하는 칸

연한 파란색 배경 — **상세 내용 · 수량 · 비고 · 할인**, 그리고 공급받는자 정보.
나머지는 전부 자동 계산입니다.

## 쓰기 전에 할 일

**단가표의 단가는 전부 예시입니다.** 회사 기준 단가로 반드시 교체하세요.
품목 18종은 경영컨설팅에서 흔한 항목으로 채워 두었습니다
(정부지원사업 · 인증등록 · 창업지원 · 교육특강 · IR투자 · 경영자문 · 기타).
목록에 없는 품목은 단가표에 행을 추가하면 드롭다운에 바로 반영됩니다.

## 검산

샘플 3건(사업계획서 1건 + 특강 4시간 + 멘토링 10회, 할인 50만원)을 넣고
LibreOffice 로 재계산해 확인했습니다.

```
소계 5,700,000 − 할인 500,000 = 공급가액 5,200,000
부가세 520,000 → 합계 5,720,000
한글 표기 : 금 5,720,000원정 (부가세 포함)
```

## 다시 만들기

```bash
pip install openpyxl
python3 build.py
```

품목 행 범위는 `build.py` 상단의 `R0, R1` 로 바꿉니다
(현재 24~41행, 18행). 바꾸면 소계 수식도 함께 따라갑니다.
