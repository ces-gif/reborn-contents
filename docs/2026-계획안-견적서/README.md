## 강사료 산정 근거

발주처 「3. 강사수당 지급기준 — 가. 일반강의 강사수당」을 `강사수당 지급기준` 시트에
원문 그대로 옮겼습니다. 등급별 적용대상을 `일반`/`공직자 등` 두 칸으로 나누고,
전문직 각주와 특1급 단서(`30(20*)`)까지 포함했습니다.

| 등급 | 최초 1시간 | 초과 매시간 | 2시간 환산 |
|---|---:|---:|---:|
| 특1급 | 400,000 | 300,000 | 700,000 |
| 특2급 | 300,000 | 200,000 | 500,000 |
| 가급 | 280,000 | 120,000 | 400,000 |
| **나급** | **170,000** | **80,000** | **250,000** |
| 다급 | 100,000 | 50,000 | 150,000 |

창업 특강(2시간)은 **나급 250,000원**으로 계상했습니다. 2025년 원가계산서도
`주강사 수당(나급 상당)`으로 4시간 `17+8+8+8 = 410,000원`, 3시간 `17+8+8 = 330,000원`을
적용했으므로 같은 등급입니다.

강사가 중소기업 대표 등 **가급** 요건에 해당하면 2시간 400,000원까지 가능합니다.

## 예산이 맞지 않는 지점

2025년 원가계산서는 **일반관리비 6% · 이윤 10%** 를 적용했습니다. 2026년 총액
10,000,000원에 같은 요율을 쓰면 직접비 한도가 7,796,663원인데, 과업지시서의
직접비는 8,550,000원이라 **753,337원이 넘칩니다.**

시상금 2,500,000원과 AI 코딩 도구 이용료 1,500,000원이 순수 실비성 지출이라
그렇습니다. 총액을 지키려면 요율을 낮출 수밖에 없어 이렇게 계상했습니다.

| | 2025년 | 2026년 (본 견적) | 법정 한도 |
|---|---:|---:|---:|
| 일반관리비 | 6.0% | **3.0%** | 8% |
| 이윤 | 10.0% | **3.23%** | 10% |

2025년 요율을 그대로 지키려면 총액 **11,036,880원**이 필요합니다.
`참고(증액 검토)` 시트에 두 안을 나란히 두었습니다.

## 확인이 필요한 값

- **주최·주관 기관** — 2025년 값을 그대로 가져왔습니다. 2026년에도 같은지 확인 필요
- **공급자 정보** — 견적서의 사업자등록번호·주소·연락처는 비워 두었습니다
- **멘토링 트랙 수** — 계획(안)은 멘토 4인 병행(2025년과 동일)으로 잡았으나,
  과업지시서에는 `2개 트랙`으로 되어 있습니다. 둘 중 하나로 맞춰야 합니다

## 개정 이력

### 2026.09.14 — 강사료를 발주처 지급기준에 맞춤

- 창업 특강 강사료 **500,000 → 250,000원** (나급 · 2시간)
  - 종전 500,000원은 기준표상 **특2급**(전직 차관급·대기업 임원) 2시간 단가였습니다
- 차액 250,000원은 **일반관리비·이윤**으로 이전 (290,909 → 540,909원)
  - 일반관리비 2.0% → 3.0%, 이윤 1.28% → 3.23%
- 원가계산서에 `강사수당 지급기준` 시트 신설
- 총액 10,000,000원은 변동 없음

과업지시서의 `행사 운영비 및 일반관리비` 항목도 1,800,000 → 2,050,000원으로
함께 올렸습니다. 이 항목이 행사운영비 + 일반관리비 + 이윤 + 부가세를 담고 있습니다.

### 2026.09.14 (2) — 지급기준 시트를 원문 그대로 채움

등급별 단가 7개는 처음부터 기준표와 일치했습니다(재대조 완료). 적용대상 문구를
요약해 두었던 것을 원문대로 바꾸고, 빠져 있던 `공직자 등` 칸을 채웠습니다.

- `일반` / `공직자 등` 2단 구성 복원 (머리행 2줄 병합)
- 전문직 각주: 감정평가사·건축사·공인노무사·공인회계사·관세사·기술사·법무사·
  변리사·변호사·보험계리사·세무사·약사·의사
- 특1급 초과 매시간 `30(20*)` — 청탁금지법 적용 대상은 200,000원이라는 단서 명기
- 금액은 변동 없음 (나급 250,000원 유지, 총액 10,000,000원)

### 2026.09.14 (3) — 견적서·과업지시서에도 지급기준 근거 삽입

금액은 이미 맞아 고칠 것이 없었습니다. 다만 두 문서에 `나급 적용`이라고만
적혀 있어 받는 쪽에서 근거를 확인할 수 없었습니다.

- **견적서** — 2쪽 `[별지] 강사수당 지급기준` 신설.
  `일반`/`공직자 등` 2단 등급표 + 각주 5개. 본문 1쪽 구성은 그대로
- **과업지시서** — `Ⅳ. 과업 예산 집행 지침` 뒤에 `◇ 참고 — 강사수당 지급기준`
  등급표(요약본) 추가. 표가 쪽을 걸치지 않도록 쪽나눔을 넣어 8쪽 → 9쪽
- 두 문서 모두 나급 행을 노란색으로 표시
- 금액 변동 없음 (총액 10,000,000원, 강사료 250,000원)

### 2026.09.14 (4) — 견적서를 발주처 제공 양식(3안)으로 교체

발주처가 보내온 세 가지 양식 중 **3안 「프로그램(운영) 견적서」**를 골랐습니다.
나머지 둘(1안·2안)은 드론 장비임대 견적서라 수신처가 다르고 품목 구조가
장비 단가 위주여서 용역에 맞지 않습니다. 3안은 수신이 `(재)고양산업진흥원`으로
우리 발주처와 같고, `행사구분 / 연번 / 개별항목 / 단위 / 단가 / 수량 / 합계 / 비고`
구조가 우리 예산 항목에 그대로 들어맞습니다.

원가계산 구조를 3안의 4단 마무리에 맞춰 옮겼습니다.

| 3안 양식 | 본 견적 |
|---|---:|
| Sub Total | 8,550,000 |
| 프로그램 대행비 (일반관리비 3.0% + 이윤 3.23%) | 540,909 |
| 견적 합계 (VAT 제외) | 9,090,909 |
| 부가가치세 | 909,091 |
| **용역합계 (VAT 포함)** | **10,000,000** |

- 대표자 김기훈, 리본마켓 법인 직인 날인 (`assets/리본마켓_직인.png`)
- 2쪽 `[별지] 강사수당 지급기준`은 그대로 유지
- 금액 변동 없음

#### 직인이 잘리던 문제

문서 기본 문단에 걸린 `w:line="280"`을 물려받으면 인라인 이미지가 줄 높이에
잘립니다. 직인 문단만 `lineRule: AUTO`로 못박아 줄이 이미지 높이만큼 늘어나게
했습니다. 행 높이를 강제로 키우는 방식은 아래가 비어 두 줄처럼 보여 쓰지 않았습니다.
