| 산출물 | 파일 | 2025년 대응 문건 |
|---|---|---|
| 계획(안) A4 7쪽 | `..._계획안.docx` / `.pdf` | 2025 특강·멘토링 계획(안) (hwpx) |
| 견적서 A4 1쪽 | `..._견적서.docx` / `.pdf` | — (신규) |

## 다시 만들기

```bash
npm install docx
node build_plan.js  2026_바이브코딩_특강및경진대회_계획안.docx
node build_quote.js 2026_바이브코딩_특강및경진대회_견적서.docx
python3 build_xlsx.py 2026_바이브코딩_특강및경진대회_원가계산서.xlsx
soffice --headless --convert-to pdf *.docx
```

## 2025년에서 가져온 것

- **계획(안) 구성** — `□ 개요` → `□ 세부 계획(안)`(시간표) → `□ 예산(안)`
- **원가계산서 구성** — 총괄표 / 인건비 / 일반경비 3시트, 그리고 산식
  `일반관리비 → 이윤 → 총원가 → 부가세 → 합계`
- **주최·주관** — 고용노동부·한국산업인력공단 / SKT·고양산업진흥원·한국항공대학교
- **장소** — 한국항공대학교 대강당 및 스타트업 라운지

## 예산이 맞지 않는 지점

2025년 원가계산서는 **일반관리비 6% · 이윤 10%** 를 적용했습니다. 2026년 총액
10,000,000원에 같은 요율을 쓰면 직접비 한도가 7,796,663원인데, 과업지시서의
직접비는 8,800,000원이라 **1,003,337원이 넘칩니다.**

시상금 2,500,000원과 AI 코딩 도구 이용료 1,500,000원이 순수 실비성 지출이라
그렇습니다. 총액을 지키려면 요율을 낮출 수밖에 없어 이렇게 계상했습니다.

| | 2025년 | 2026년 (본 견적) | 법정 한도 |
|---|---:|---:|---:|
| 일반관리비 | 6.0% | **2.0%** | 8% |
| 이윤 | 10.0% | **1.28%** | 10% |

2025년 요율을 그대로 지키려면 총액 **11,286,880원**이 필요합니다.
`참고(증액 검토)` 시트에 두 안을 나란히 두었습니다.

## 확인이 필요한 값

- **주최·주관 기관** — 2025년 값을 그대로 가져왔습니다. 2026년에도 같은지 확인 필요
- **공급자 정보** — 견적서의 사업자등록번호·주소·연락처는 비워 두었습니다
- **멘토링 트랙 수** — 계획(안)은 멘토 4인 병행(2025년과 동일)으로 잡았으나,
  과업지시서에는 `2개 트랙`으로 되어 있습니다. 둘 중 하나로 맞춰야 합니다
