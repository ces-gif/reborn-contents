# 고양산업진흥원 용역계약 체결 서류

계약번호 제2026-81호 · 계약금액 10,000,000원(VAT 포함) · 계약기간 계약일 ~ 2026.11.6.

- 산출물: `계약체결서류_작성본.docx` / `.pdf` (A4 7쪽)
- 생성 스크립트: `build.js` (docx-js)

진흥원이 보내온 한글 양식(3번 파일)의 서식을 리본마켓 정보로 채운 **대조·검토용
사본**입니다. 원본은 한글 양식에 그대로 타이핑해 제출하고, 이 파일로 기재값을
맞춰 보는 용도입니다.

**날짜는 연도만, 직인은 뺐습니다.** 서명란 날짜는 `2026.        .        .` 처럼
연도만 찍고 월·일은 발주처가 채우도록 비웠습니다(확인서 서명란은
`2026년         월         일`, 발주날짜란은 `2026.`). 대표자란은 `(인)` 표기만
두었으니 법인인감(또는 사용인감)을 직접 날인하면 됩니다.

## 확인이 필요한 한 가지

**정부 수입인지** — 제출 기준은 계약금액 1천만원 **초과**입니다. 본 계약은 기재금액이
정확히 1천만원(부가세 제외 시 9,090,909원)이라 초과에 해당하지 않아 대상이 아닌
것으로 보입니다. 다만 부가세 포함 여부 해석이 기관마다 다를 수 있어 담당자 확인을
권합니다.

양식 안내에 "문서 작성 일자는 응답서 제출 일자로 작성"이라고 되어 있으나, 제출일은
발주처가 기재하므로 연도만 표기하고 월·일은 비워 뒀습니다. 표준계약서의 계약일자도
안내대로 공란입니다.

## 표준계약서 (진흥원 제공 1번 파일)

상호·사업자등록번호·주소·대표자·연락처·계약금액·계약기간이 **진흥원 측에서 이미
기재**되어 있어 작성할 것이 없습니다. 2부 출력해 대표란에 날인하고 계약일자는
공란으로 둡니다. 간인은 발주처 계약 천공으로 갈음합니다.

