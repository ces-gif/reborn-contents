# 2026 바이브 코딩 특강 및 창업 경진대회 — 현수막 / X배너

시안 2종(A 기본형 / B 미래형) × 2규격 = PDF 4개입니다.

| 규격 | A안 기본형 | B안 미래형 |
|---|---|---|
| 현수막 **5,000 × 900 mm** | `현수막_5000x900_A안_기본형.pdf` | `현수막_5000x900_B안_미래형.pdf` |
| X배너 **600 × 1,800 mm** | `X배너_600x1800_A안_기본형.pdf` | `X배너_600x1800_B안_미래형.pdf` |
| 포스터 **A2 420 × 594 mm** | `포스터_A2_420x594_A안_기본형.pdf` | `포스터_A2_420x594_B안_미래형.pdf` |
| 포스터 **A1 594 × 841 mm** | `포스터_A1_594x841_A안_기본형.pdf` | `포스터_A1_594x841_B안_미래형.pdf` |

포스터는 교내 게시 표준인 A2를 기본으로 하고, 게시대용 A1을 함께 넣었습니다.

미리보기 PNG는 `시안_*.png`.

## 두 시안의 차이

- **A안 기본형** — 남색 그라데이션 + 노드 네트워크. 기관 행사물의 무난한 톤.
- **B안 미래형** — 검정에 가까운 딥스페이스 + 소실점으로 모이는 네온 원근 그리드,
  지평선 발광, 시안→바이올렛 그라데이션, 제목 글로우. 네온 프레임 추가.

두 규격 모두 국내 실사출력에서 가장 널리 쓰는 표준입니다. 현수막 5000×900은
옥외 게시대 규격, X배너 600×1800은 표준 거치대 규격입니다.

## 다시 만들기

```bash
python3 build.py          # 현수막·X배너  A·B × 2규격 = 4개
python3 build_poster.py   # 포스터        A·B × A2/A1 = 4개
```

`build_poster.py`는 `build.py`에서 테마·로고·문구를 그대로 가져다 씁니다.
포스터 치수는 전부 `rem`으로 쓰고 `1rem = 페이지 폭의 1%`로 잡아, A2와 A1을
레이아웃 한 벌로 뽑습니다. mm를 직접 박으면 규격마다 다시 짜야 합니다.

테마는 `THEMES` 딕셔너리(색상)와 배경 함수 `net()`(A) / `grid()`(B) 두 곳에서만
갈라집니다. 레이아웃은 한 벌을 공유합니다.

크롬 헤드리스로 `@page`에 mm 단위를 직접 지정해 뽑으므로 글자는 벡터로 남습니다.
출력소에 PDF 그대로 넘기면 됩니다.

## 로고 4종

네 기관 로고를 모두 노출했습니다. 하단 흰 바에 `주최 / 주관`으로 묶었습니다.

- **주최** 고용노동부 · 한국산업인력공단
- **주관** 고양산업진흥원 · K-하이테크 플랫폼

`logo/` 에 배경을 투명 처리한 PNG를 넣어 두었습니다. 고양산업진흥원은 받은
`.ai`(PDF 호환)에서 600dpi로 뽑았고, 나머지는 보내주신 이미지에서 흰 바탕을
지우고 여백을 잘라냈습니다.

K-하이테크 플랫폼 `.ai`는 여러 변형이 담긴 시안 시트여서, 보내주신 단일 로고
이미지를 썼습니다. 벡터가 필요하면 해당 변형만 추출한 `.ai`를 주세요.

## 만들 때 걸린 것

- `height:100%`는 인쇄 뷰포트 기준으로 잡혀 로고 바가 바닥에 붙지 않고 폭도
  잘립니다. `.wrap`에 mm를 직접 박아야 합니다.
- 배경 그라데이션 색값에 문자가 하나라도 섞이면 선언 전체가 무효가 되어
  배경이 흰색이 됩니다. 흰 글씨를 쓰면 통째로 안 보입니다.
- 로고는 종횡비가 제각각(3.1~7.5)이라 같은 높이로 넣으면 균형이 깨집니다.
  `l-molab` 등 클래스로 하나씩 지정했습니다.
- 로고 바를 flex로 가운데 정렬하면 `주최`/`주관` 줄이 서로 어긋납니다. 각 묶음의
  폭이 달라 중앙 정렬 기준점이 달라지기 때문입니다. **grid로 바꿔 라벨을 한 열에
  고정**했습니다 (현수막 4열 한 줄, X배너 2열 두 줄).
- B안 원근 그리드는 하단 본문 글자와 겹쳐 읽기 어렵습니다. 그리드를 지우는 대신
  `.scrim` 한 겹을 깔아 질감은 남기고 대비만 확보했습니다.
- 배경 노드망의 선 굵기를 뷰박스 고정값으로 두면 **뷰박스가 작은 포스터에서만
  선이 굵게** 나와 글자를 덮습니다. `net()`이 `min(w,h)`에 비례해 굵기와 점 크기를
  정하도록 고쳤습니다. 판형별 농도는 `op` 인자로 조절합니다.
