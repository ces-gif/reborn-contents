# 2026 바이브 코딩 특강 및 창업 경진대회 — 현수막 / X배너 / 포스터

시안 2종(A 기본형 / B 미래형) × 4규격 = PDF 8개입니다.

| 규격 | A안 기본형 | B안 미래형 |
|---|---|---|
| 현수막 **5,000 × 900 mm** | `현수막_5000x900_A안_기본형.pdf` | `현수막_5000x900_B안_미래형.pdf` |
| X배너 **600 × 1,800 mm** | `X배너_600x1800_A안_기본형.pdf` | `X배너_600x1800_B안_미래형.pdf` |
| 포스터 **A2 420 × 594 mm** | `포스터_A2_420x594_A안_기본형.pdf` | `포스터_A2_420x594_B안_미래형.pdf` |
| 포스터 **A1 594 × 841 mm** | `포스터_A1_594x841_A안_기본형.pdf` | `포스터_A1_594x841_B안_미래형.pdf` |

포스터는 교내 게시 표준인 A2를 기본으로 하고, 게시대용 A1을 함께 넣었습니다.

미리보기 PNG는 `시안_*.png`.

## 두 시안의 차이

- **A안 기본형** — 남색 그라데이션 + 노드 네트워크. 기관 행사물의 무난한 톤.
- **B안 미래형** — 검정에 가까운 딥스페이스 + 소실점으로 모이는 네온 원근 그리드,
  지평선 발광, 시안→바이올렛 그라데이션, 제목 글로우. 네온 프레임 추가.

두 규격 모두 국내 실사출력에서 가장 널리 쓰는 표준입니다. 현수막 5000×900은
옥외 게시대 규격, X배너 600×1800은 표준 거치대 규격입니다.

## 다시 만들기

```bash
python3 build.py          # 현수막·X배너  A·B × 2규격 = 4개
python3 build_poster.py   # 포스터        A·B × A2/A1 = 4개
```

`build_poster.py`는 `build.py`에서 테마·로고·문구를 그대로 가져다 씁니다.
포스터 치수는 전부 `rem`으로 쓰고 `1rem = 페이지 폭의 1%`로 잡아, A2와 A1을
레이아웃 한 벌로 뽑습니다. mm를 직접 박으면 규격마다 다시 짜야 합니다.

테마는 `THEMES` 딕셔너리(색상)와 배경 함수 `net()`(A) / `grid()`(B) 두 곳에서만
갈라집니다. 레이아웃은 한 벌을 공유합니다.

크롬 헤드리스로 `@page`에 mm 단위를 직접 지정해 뽑으므로 글자는 벡터로 남습니다.
출력소에 PDF 그대로 넘기면 됩니다.

## 로고 4종

네 기관 로고를 모두 노출했습니다. 하단 흰 바에 `주최 / 주관`으로 묶었습니다.

- **주최** 고용노동부 · 한국산업인력공단
- **주관** 고양산업진흥원 · K-하이테크 플랫폼

`logo/` 에 배경을 투명 처리한 PNG를 넣어 두었습니다. 고양산업진흥원은 받은
`.ai`(PDF 호환)에서 600dpi로 뽑았고, 나머지는 보내주신 이미지에서 흰 바탕을
지우고 여백을 잘라냈습니다.

K-하이테크 플랫폼 `.ai`는 여러 변형이 담긴 시안 시트여서, 보내주신 단일 로고
이미지를 썼습니다. 벡터가 필요하면 해당 변형만 추출한 `.ai`를 주세요.

**X배너 / 포스터** — 위 내용에 더해 4단계 일정(특강·멘토링·예선·결승), 총 시상 규모
2,500,000원, 참가대상·장소·문의처

## 만들 때 걸린 것

- `height:100%`는 인쇄 뷰포트 기준으로 잡혀 로고 바가 바닥에 붙지 않고 폭도
  잘립니다. `.wrap`에 mm를 직접 박아야 합니다.
- 배경 그라데이션 색값에 문자가 하나라도 섞이면 선언 전체가 무효가 되어
  배경이 흰색이 됩니다. 흰 글씨를 쓰면 통째로 안 보입니다.
- 로고는 종횡비가 제각각(3.1~7.5)이라 같은 높이로 넣으면 균형이 깨집니다.
  `l-molab` 등 클래스로 하나씩 지정했습니다.
- 로고 바를 flex로 가운데 정렬하면 `주최`/`주관` 줄이 서로 어긋납니다. 각 묶음의
  폭이 달라 중앙 정렬 기준점이 달라지기 때문입니다. **grid로 바꿔 라벨을 한 열에
  고정**했습니다 (현수막 4열 한 줄, X배너 2열 두 줄).
- B안 원근 그리드는 하단 본문 글자와 겹쳐 읽기 어렵습니다. 그리드를 지우는 대신
  `.scrim` 한 겹을 깔아 질감은 남기고 대비만 확보했습니다.
- 배경 노드망의 선 굵기를 뷰박스 고정값으로 두면 **뷰박스가 작은 포스터에서만
  선이 굵게** 나와 글자를 덮습니다. `net()`이 `min(w,h)`에 비례해 굵기와 점 크기를
  정하도록 고쳤습니다. 판형별 농도는 `op` 인자로 조절합니다.

# 시상식 현수막 · 대형 상금 패널 (build_award.py)

시상식 당일에 쓰는 두 가지입니다. 모집용 현수막(`현수막_5000x900_*`)과는 별개로
`build_award.py` 가 따로 만듭니다.

## 출력 사이즈

| 파일 | 실물 크기 | 소재 |
|---|---|---|
| `시상식_현수막_5000x900.pdf` | **5000 × 900mm** (1장) | 현수막 천, 실사출력 |
| `시상식_전광판_8.3x1.pdf` | **1660 × 200mm** (8.3:1, 1장) | 대강당 상단 전광판 |
| `시상식_슬라이드_16x9.pdf` | **338.67 × 190.5mm** (16:9, 1장) | 대강당 스크린 · PPT 삽입 |
| `상금패널_900x600.pdf` | **900 × 600mm** (3장) | 폼보드 5mm 또는 포맥스 |

상금 패널은 사진 촬영용 대형 보드입니다. 수상자가 양손으로 드는 크기라
900 × 600mm 가 적당합니다. 더 크게 가려면 `panel()` 의 `W, H` 만 바꾸면 되고,
글자는 전부 mm 로 잡아 놓아 비율이 그대로 따라옵니다.

PDF 는 벡터입니다. 5m 현수막도 확대 손실이 없습니다. 눈으로 볼 때는
`*_미리보기.png` 를 보세요(인쇄용 아님).

## 상금 패널 3매 구성

| 쪽 | 상격 | 수상자 | 금액 |
|---|---|---|---|
| 1 | 대상 | 유진수 · 박준호 | 1,000,000원 |
| 2 | 최우수상 | 김현수 | 500,000원 |
| 3 | 우수상 | 하정묵 | 300,000원 |

**장려상 6팀은 상패를 만들지 않습니다.** 상장만 수여합니다. 되살리려면
`PANEL_RANKS` 에 `'장려상'` 을 넣으면 9매로 돌아옵니다 — 명단과 금액은
`AWARDS` 에 그대로 남겨 뒀습니다.

시상 규모는 장려상 6팀 각 100,000원을 포함해 합계 **2,500,000원**이고,
포스터에 적은 총 시상 규모와 맞습니다.

수상자·금액은 `AWARDS` 리스트 한 곳에만 있습니다. 명단이 바뀌면 거기만 고치면
상장(`docs/2026-상장/`)과 따로 놀지 않게 같은 형식으로 다시 뽑힙니다.

행사 날짜는 `WHEN` 한 줄입니다.

## 현수막 디자인

5m × 0.9m 는 가로로 긴 판형이라 가운데가 비기 쉽습니다. **좌(행사명) / 중(엠블럼) /
우(일시·장소·로고)** 3열 그리드로 잡고, 가운데를 월계관 엠블럼으로 채웠습니다.

- **월계관 엠블럼** — 오른쪽 가지만 그린 뒤 좌우 반전해 붙여 반드시 대칭입니다
  (`wreath()`). 위가 트인 자리에 금색 별을 얹었습니다.
- **시 상 식** 글자는 위에서 아래로 밝은 금 → 금 → 밝은 금 그라데이션입니다.
  PDF 안에서 이미지가 아니라 **실제 글자**로 남아 5m 로 키워도 깨지지 않습니다
  (`pdftotext` 로 확인).
- 엠블럼 안쪽에 어두운 원판(`.disc`)을 깔았습니다. 이게 없으면 금색 글자가
  금색 잎에 묻혀 안 읽힙니다.
- 금테는 3겹 — 위아래 굵은 금띠, 안쪽 실선, 네 귀퉁이 꺾쇠.
- 왼쪽 아래 한 줄에 상격과 총 시상 규모를 넣어 왼쪽 블록 무게를 맞췄습니다.
- 5m 짜리는 글자를 작게 쓰면 멀리서 안 읽힙니다. 행사명 168mm, 일시·장소 76mm,
  주최·주관 로고 60~76mm 로 잡았습니다. 로고 바는 2열 두 줄이 아니라 **4열 한 줄**
  이라야 가로로 펴져 여백이 줄고 글자도 커집니다.

## 대강당 상단 전광판 (8.3 : 1)

현장 사진에서 재어 보니 상단 전광판의 보이는 면이 **약 1930 × 232px, 8.3 : 1** 입니다
(같은 사진의 아래 스크린이 1927 × 1089 = 1.770 으로 나와 16:9(1.778)와 0.5% 밖에
차이나지 않으므로, 사진 왜곡은 무시할 만합니다).

5000 × 900(5.6:1)을 그대로 띄우면 **좌우가 남고 위아래가 잘립니다.** 실제로 현장
사진에서 위쪽 금색 띠가 잘려 있었습니다. 그래서 같은 디자인을 8.3:1 로 다시 짰습니다.

치수는 `STRIP_W, STRIP_H` 두 줄입니다. 화면용이라 **비율만 맞으면 실제 mm 는 상관없습니다.**
AV 담당에게 정확한 해상도(예: 1920 × 232)를 받으면 그 값을 넣으면 됩니다.

레이아웃은 `1rem = 화면 높이의 1%` 로 잡아 두어, 비율이 바뀌어도 글자 크기가 따라옵니다.

16:9 슬라이드는 현수막과 같은 내용을 세로로 쌓은 것입니다. 5m 현수막은 가로가 길어
좌·중·우 3단이지만, 16:9 는 세로 여유가 있어 행사명 → 엠블럼 → 일시·로고 순으로
쌓아야 가운데가 비지 않습니다. 쪽 크기는 960 × 540pt 로 정확히 16:9 이므로
파워포인트 「와이드스크린」 슬라이드에 그대로 들어갑니다.

일시 `WHEN`, 장소 `WHERE` 는 파일 맨 위 한 줄씩입니다. 날짜를 바꾸면
`docs/2026-상장/` 의 `DATE` 도 같이 맞춰야 합니다 — 상장에 찍히는 날짜가
시상일이라서 그렇습니다.

## 만들 때 걸린 것

- 처음 현수막은 가운데가 텅 비고 글씨가 양 끝으로 밀렸습니다. 5m 짜리는
  `justify-content:space-between` 이 아니라 **좌(행사명) / 중(시상식) / 우(일시·로고)
  세 구역**으로 명시해야 균형이 잡힙니다.
- 그 `space-between` 은 좌우 블록 폭이 달라 **가운데 엠블럼이 화면 중앙에서 밀립니다.**
  배경 방사선의 소실점은 정확히 50% 라 어긋난 게 눈에 보입니다.
  `grid-template-columns:1fr auto 1fr` 로 바꿔야 가운데가 진짜 가운데입니다.
- 배경 금빛 입자를 크고 많게 깔면 물방울무늬처럼 보입니다. 지름을 폭의 0.05~0.17%
  로 줄이고 개수를 70개로 낮췄습니다.
- 무대 조명을 `clip-path` 사다리꼴로 만들면 **경계선이 그대로 보입니다.** 지우고
  엠블럼에 방사형 후광(`.aura`)만 남겼습니다.
- 월계관 안쪽에도 잎을 한 줄 더 그렸더니 글자 자리가 없어졌습니다. 바깥 한 줄만
  남기고 반지름을 72 → 78 로 키웠습니다.
- 한자 `金` 은 나눔스퀘어에 글리프가 없어 **공백으로 출력**됩니다. 금액 설명은
  `금 일백만원정` 처럼 한글로 적었습니다.
- 이름 구분자로 전각 쉼표(`，`)를 쓰면 앞뒤 간격이 벌어져 읽기 나쁩니다.
  가운뎃점(` · `)으로 바꿨습니다.
- 4명 팀(`김성훈 · 김채원 · 신재훈 · 김수빈`)이 줄바꿈되지 않도록 `.who` 글자
  크기를 이름 길이에 따라 56 / 46 / 34mm 로 내립니다.
