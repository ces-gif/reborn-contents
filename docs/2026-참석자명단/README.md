# 참석자 명단 및 참가자 DB

과업지시서 **Ⅲ-가**의 「참가자 DB(소속·학번·연락처·팀 구성 여부) 구축」과,
결과보고·정산 때 내는 **행사별 참석자 명단**을 함께 준비한 것입니다.

| 산출물 | 쓰임 |
|---|---|
| `창업특강_참석자명단.pdf` | **9. 28.(월) 14:00~16:00 현장 서명부** · A4 가로 10쪽 · **200명분** |
| `최종발표_참석자명단.pdf` | 10. 22.(목) 현장 서명부 · A4 가로 3쪽 · 60명분 |
| `서류평가_점수표_심사위원용.pdf` | 예선 심사용 팀별 점수표 · A4 세로 12장 |
| `서류평가_총괄표.pdf` | 심사위원별 20팀 집계표 · A4 세로 1장 |
| `참가자DB_및_참석자명단.xlsx` | 전 과정 관리 대장 (7시트) |
| `명단_build.py` / `점수표_build.py` / `db_build.py` | 위 파일 생성 스크립트 |

## 서명부 (PDF)

한 쪽에 20명씩, 다음 칸으로 받습니다.

> 연번 · 성명 · 소속 · 학년 · 개인정보 동의(□) · 서명

- 쪽마다 **행사명 · 일시 · 장소 · 주관**이 박혀 있어 낱장이 섞여도 구분됩니다.
- 하단에 **개인정보 수집·이용 고지문**을 넣었습니다. 이 고지 없이 받은 명단은
  정산 때 반려될 수 있습니다.
- **연락처·이메일은 받지 않습니다.** 현장에서 오래 걸리고, 종이에 남은 개인정보는
  보관 부담이 큽니다. 연락 수단은 온라인 신청 폼으로 받으므로 서명부에는
  참석 사실 확인에 필요한 최소 항목만 둡니다. 수집 고지문도 `성명, 소속, 학년`
  으로 맞춰 두었습니다.
- 기관 로고 4종이 하단에 들어갑니다.

명단에 **운영사(리본마켓) 이름은 넣지 않았습니다.** 상단 기재란은 `주관 고양산업진흥원`
까지만 표기합니다.

**온라인 팀별 멘토링(10. 13. ~ 10. 18.)은 서명부가 없습니다.** 비대면이라 서명을
받을 수 없어, xlsx 의 `온라인멘토링` 시트에 일시·멘토·참석 인원·결과 요약을
기록하는 방식으로 갈음합니다. 화면 캡처나 회의 참석자 목록을 함께 남겨두시면
정산 근거로 쓰기 좋습니다.

인원이 넘칠 것 같으면 쪽수만 늘리면 됩니다.

```python
# 명단_build.py 의 EVENTS 마지막 숫자가 쪽수 (쪽당 20명)
('창업특강_참석자명단', '창업 특강',
 '2026. 9. 28.(월) 14:00 ~ 16:00', '한국항공대학교 대강당', 10),
```

## 서류 평가 점수표

배점은 총 100점입니다.

| 평가 항목 | 배점 |
|---|---|
| 문제 정의 능력 | 10 |
| AI를 통한 솔루션의 적합성 | 20 |
| 시장 규모 | 15 |
| 비즈니스 모델 타당성 | 20 |
| 아이템 구현에 대한 계획 | 20 |
| 사업 의지 | 15 |

- `서류평가_점수표_심사위원용.pdf` — **팀 한 곳당 한 장**입니다. 항목마다 채점
  기준을 한 줄로 달아 두어 심사위원 두 분의 눈높이가 벌어지지 않게 했습니다.
  종합 의견란과 서명란이 있습니다. 12장이 들어 있고, 팀 수에 맞춰
  `점수표_build.py` 의 `sheet_page() * 12` 숫자만 바꾸면 됩니다.
- `서류평가_총괄표.pdf` — 심사위원 한 분이 20팀을 한 장에 집계하는 표입니다.
  항목별 점수·합계·순위·합격 여부 칸이 있습니다.
- 종이로 받은 점수는 xlsx `서류심사_결과` 시트에 옮기면 **소계와 평균이 자동
  계산**됩니다. 심사위원 2인의 평균으로 순위를 매기고 결승 진출 10개 팀을 정합니다.

## 관리 대장 (xlsx)

| 시트 | 내용 |
|---|---|
| 안내 | 파일 용도, 쓰는 법, 개인정보 취급 |
| 창업특강_참석 | 9. 28. 서명부를 옮겨 적는 시트 (90행) |
| 참가팀_명단 | 서류 접수 팀 전체 — 구글폼 응답을 붙여넣어 관리 (60행) |
| 서류심사_결과 | 심사위원 2인 **항목별 점수** · 소계·평균 자동 계산 · 합격 여부 (60행) |
| 온라인멘토링 | 팀별 멘토링 일시·멘토·결과 요약 (30행) |
| 최종발표_참석 | 학생·심사위원·스태프 구분 기록 · 수상 (60행) |
| 집계 | 위 시트를 **수식으로 자동 집계** |

- 드롭다운이 걸린 칸(참가 형태, 합격 여부, 구분, 수상 등)은 목록에서 고르셔야
  집계 수식이 맞습니다. 직접 타이핑하면 표기가 갈려 카운트가 틀어집니다.
- `집계` 시트의 C열은 전부 수식입니다. 값을 덮어쓰지 마세요.
- 행이 모자라면 마지막 행을 복사해 아래로 늘리면 테두리와 연번이 따라옵니다.
  다만 `집계` 수식의 범위는 자동으로 늘지 않으니 같이 고쳐야 합니다.

## 개인정보

명단에는 학생 연락처와 이메일이 그대로 들어갑니다.

- 수집 목적(참석 확인·결과보고·정산) 외에 쓰지 않습니다.
- 사업 종료 및 정산 완료 후 **6개월 이내 파기**합니다.
- 진흥원 등 외부에 파일을 보낼 때는 **연락처·이메일 열을 지운 사본**을 쓰세요.
  참석 인원 확인이 목적이면 그 두 열은 없어도 됩니다.

## 다시 만들기

```bash
python3 명단_build.py     # 서명부 PDF 2종
python3 점수표_build.py   # 서류평가 점수표 · 총괄표 PDF
python3 db_build.py       # 관리 대장 xlsx
```

서명부는 크롬 헤드리스로 `@page` 에 mm 를 직접 지정해 뽑습니다. 글자가 벡터로
남아 출력소에 그대로 넘겨도 되고, 사무실 프린터로 뽑아도 됩니다.
