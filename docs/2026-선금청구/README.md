# 고양산업진흥원 선금 청구 서류

진흥원이 보내온 한글 양식(선금·잔금 청구 시 필요한 서류)의 서식을 리본마켓
정보로 채운 **대조·검토용 사본**입니다. 원본은 한글 양식에 그대로 타이핑해
제출하고, 이 파일로 기재값을 맞춰 보는 용도입니다.

- 산출물: `선금청구서류_작성본.docx` / `.pdf` (A4 6쪽)
- 생성 스크립트: `build.js` (docx-js)

**작성일은 2026. 9. 28. 로 기재했습니다.** 직인만 공란이니 대표자란에
법인인감(또는 사용인감)을 직접 날인하세요.

기간·계약금액·선금청구액)를 모두 담고 붙임 목록까지 붙여 두었으니 그대로
쓰시면 됩니다.

## 금액

| 항목 | 금액 | 근거 |
|---|---|---|
| 계약금액 | 10,000,000원 (부가세 포함) | 계약서 |
| **선금 청구액** | **5,000,000원** | 계약금액의 50% (한도 70% 이내) |
| 잔금 예정액 | 5,000,000원 | 계약금액 − 선금 |

선금 한도는 계약금액의 70%입니다(지방회계법 시행령 제44조 제13호). 한도 안에서
50%를 청구하므로 절사할 금액이 없습니다.

## 선금 사용 계획 (5,000,000원)

**선금 개시 전에 집행되는 항목**만 골랐습니다. 상금과 결승 심사수당은 10월 22일
행사 당일·이후에 나가는 돈이라 잔금으로 돌렸습니다.

| 구분 | 경비별 | 금액 |
|---|---|---|
| 인건비 | 1:1 창업 멘토링비 (150,000 × 10팀) | 1,500,000 |
| 인건비 | 예선 서류 평가료 (150,000 × 2명) | 300,000 |
| 인건비 | 창업 특강 강사료 (나급 2시간) | 250,000 |
| 재료비 | AI 코딩 도구 이용료 (50,000 × 30명) | 1,500,000 |
| 재료비 | 홍보물 · 인쇄비 | 700,000 |
| 경비 | 행사 운영비 (총 2,050,000원 중 선금 집행분) | 750,000 |
| | **계** | **5,000,000** |

잔금 5,000,000원 = 상금 및 부상 2,500,000 + 결승 심사수당 1,200,000 +
행사 운영비 잔여 1,300,000.

## 아직 준비해야 하는 것

**이행(선금)보증보험증권** — 이것만 있으면 제출할 수 있습니다. 서울보증보험에서
발급받으시고, 아래 두 가지를 반드시 맞춰야 합니다.

- **보증기간** : 증권발급일 ~ **2027. 1. 5. 이상** (계약종료일 2026. 11. 6. + 60일)
- **보증금액** : 선금청구액 5,000,000원 **+ 보증기간 이자상당액**

보증금액에 이자상당액을 빼고 딱 5,000,000원으로 끊으면 반려됩니다. 발급 창구에
"지방계약 선금보증, 계약종료일 + 60일"이라고 말씀하시면 알아서 계산해 줍니다.

그 밖에 **지방세·국세 완납증명 각 1부**, **전자세금계산서**, **기업 명의 통장
사본(원본대조필)** 을 함께 내시면 됩니다.

## 해당 없는 것 두 가지

**지역개발채권 매입필증** — 안내문에 "수의계약 포함하여 계약금액 2,000만원 미만
건은 제외(부가세 포함 2,200만원 미만)"라고 되어 있습니다. 본 계약은 부가세 포함
10,000,000원이라 **제외 대상**입니다. 선금·잔금 모두 필요 없습니다. (선금 때
필증을 냈다면 잔금이 2천만원 미만이어도 내야 한다는 단서가 있는데, 애초에 선금에서
제외 대상이므로 해당되지 않습니다.)

**4대보험 완납증명 · 하자보증서** — 안내문에 `(공사 必)`로 표시된 항목입니다.
본 계약은 용역이라 대상이 아닌 것으로 보이나, 잔금 청구 전에 담당자 확인을
권합니다.

## 다시 만들기

```bash
npm install docx jszip
node build.js 선금청구서류_작성본.docx
soffice --headless --convert-to pdf 선금청구서류_작성본.docx
```

금액이나 사용 계획이 바뀌면 `build.js` 위쪽의 `V` 객체와 `사용내역` 배열만
고치면 됩니다.
