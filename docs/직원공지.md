## 2. 어떻게 찍나요 — 이게 제일 중요합니다

**상품 하나당 둘 중 아무거나**로 찍어주세요.

### 방법 A — 두 장 (권장)

1. **상품 사진** 1장
2. **가격표 사진** 1장

순서는 상관없습니다. 상품 → 가격표든, 가격표 → 상품이든 됩니다.

### 방법 B — 한 장

상품과 가격표가 **한 화면에 같이** 나오게 1장.

---

### ✅ 지켜주시면 결과가 확 좋아집니다

- **한 상품 찍고 → 다음 상품**. 이 순서를 지켜주세요.
  여러 상품을 섞어 찍으면 엉뚱한 가격표가 붙습니다.
- **가격표 글씨가 읽히게** 찍어주세요. 흐리면 "확인 필요"로 빠지고 카드가 안 만들어집니다.
- **가격표를 테이프나 손으로 가리지 마세요.**
- 사진은 **똑바로** 찍어주세요. 옆으로 누우면 글씨를 못 읽습니다.
- 상품 사진은 **물건 전체**가 보이게. 너무 가까이 찍지 마세요.

### ❌ 이러면 콘텐츠가 안 나옵니다

- 가격표만 있고 상품 사진이 없는 경우 → 정보용으로만 기록되고 카드뉴스는 안 만듭니다
- 가격표가 아예 없는 경우 → 가격을 지어내지 않습니다. 카드뉴스를 안 만듭니다
- 매장 전경, 간판, 영수증 사진 → 자동으로 걸러집니다

## 3. 자동으로 만들어지는 것

낮 12시에 `콘텐츠 발행 / (오늘 날짜)` 안에 이렇게 들어옵니다.

| 폴더 | 내용 |
| --- | --- |
| `카드뉴스` | 인스타 스토리 크기(1080×1920) PNG. 상품마다 1장 |
| `블로그` | 오늘의 BEST5 블로그 글 (`.md` + 네이버 붙여넣기용 `.html`) |
| `소셜` | 카톡 공지 문구, 인스타 캡션 |
| `_data/리포트.md` | **몇 개 만들었는지, 뭐가 확인 필요한지** |

### 📋 매일 `리포트.md` 를 먼저 봐주세요

여기에 이런 게 적힙니다.

- 사진 몇 장 → 상품 몇 개 → 카드뉴스 몇 장
- **확인 필요** 목록 — 가격표가 흐려서 못 읽었거나, 상품과 가격표가 안 맞는 경우

확인 필요로 뜬 상품은 **가격표를 다시 찍어서 올려주시면** 다음 날 반영됩니다.

## 4. 자주 나오는 질문

**Q. 사진을 몇 장까지 올려도 되나요?**
제한 없습니다. 어제 평택에서 31장 올려서 상품 19개, 카드뉴스 11장이 나왔습니다.

**Q. 11시 30분을 넘겼어요.**
그대로 두세요. 다음 날 낮 12시에 자동으로 나갑니다. 지우지 마세요.

**Q. 잘못 올렸어요.**
그 사진만 지우시면 됩니다. 12시 전에 지우면 반영 안 됩니다.

**Q. 같은 상품을 3~4장 찍어도 되나요?**
됩니다. 가격표 1장 + 상품 사진 여러 장이면 가장 잘 나온 사진이 카드에 쓰입니다.

**Q. "중고"라고 써도 되나요?**
아니요. 리본마켓·여우마켓은 **리퍼브(검수를 마친 새 상품)** 매장입니다.
자동 생성물에도 "중고"라는 단어는 절대 들어가지 않습니다.
