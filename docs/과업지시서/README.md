# 한국항공대학교 바이브 코딩 기반 학생창업 경진대회 과업지시서

원본(2026.07.20, AI 기반 학생창업 경진대회)을 **바이브 코딩(Vibe Coding)** 주제로 바꾸고,
일정을 `강의 → 멘토링 → 예선(서류) → 결승(PT)` 순서로 재구성한 개정본입니다.

- 산출물: `한국항공대_바이브코딩_창업경진대회_과업지시서.docx` (A4 6쪽, 작성일 2026.09.01)
- 생성 스크립트: `build.js` (docx-js)

## 다시 만들기

```bash
npm install docx
node build.js 한국항공대_바이브코딩_창업경진대회_과업지시서.docx
```

## 원본 대비 바뀐 점

### 1) 주제
AI 활용 아이템 → **바이브 코딩으로 직접 구현한 프로토타입** 기반 아이템.
기획서만 내는 대회가 아니라 **동작하는 결과물(데모 URL·저장소 링크)** 을 심사 대상으로 삼습니다.

### 2) 순서
원본은 `서류평가 → 특강 → 멘토링 → 본선`이었으나,
개정본은 요청대로 `특강 → 멘토링 → 예선(서류) → 결승(PT)` 입니다.
멘토링 대상은 서류 통과팀이 아니라 **특강 참가자·대회 참가 신청자 중 멘토링 신청 팀**입니다.

### 3) 일정 (특강은 지정일, 나머지는 매주 목요일)

| 단계 | 날짜 |
|---|---|
| 홍보 및 모집 | 9.7(월) ~ 9.25(금) |
| ① 창업 특강 (바이브 코딩 실습, 2시간) | **9.28(월)** — 발주처 지정일 |
| ② 1:1 창업 멘토링 | **10.8(목)** |
| 예선 접수 마감 | 10.13(화) 18:00 |
| ③ 예선 (서류평가) | **10.15(목)** |
| 예선 결과 발표 | 10.16(금) |
| ④ 결승 (PT) 및 시상식 | **10.22(목)** |
| 성과물 제출 | ~ 11.5(목) |

특강 9.28은 월요일이라 "수·목·금" 규칙의 예외이며, 이후 3개 행사는 모두 목요일입니다.

### 4) 예산 — 총액 10,000,000원 유지

`행사 운영비 및 일반관리비` 2,800,000 → 2,500,000으로 300,000원을 덜어
**실습 환경비(AI 코딩 도구 크레딧) 300,000원**을 신설했습니다. 다른 항목은 원본 그대로입니다.

| 구분 | 금액 (원) |
|---|---:|
| 상금 및 부상 | 3,200,000 |
| 전문가 활용비 (강사료·멘토링·서류평가·VC 심사) | 3,300,000 |
| 실습 환경비 (신설) | 300,000 |
| 홍보 및 인쇄비 | 700,000 |
| 행사 운영비 및 일반관리비 | 2,500,000 |
| **총 합계** | **10,000,000** |

## 문서 서식

관공서 과업지시서 형식에 맞춰 편집했습니다.

- **표지** — 이중 테두리, 남색 제목 괘선, 문서정보 표(과업명·발주처·수행사·예산·작성일)
- **머리말/바닥글** — 머리말에 과업명, 바닥글에 쪽번호(표지 제외)
- **장 제목** — `Ⅰ~Ⅵ` 남색 바탕 흰 글씨 / **절 제목** — `가·나·다` 남색 글씨 + 밑줄
- **표** — 남색 머리행, 줄무늬 배경, `구분` 열 세로 병합, 합계행 강조
- **서체** — 맑은 고딕(`w:hint="eastAsia"` 지정, 본문 10.5pt / 줄간격 1.4)

### 만들 때 주의할 점

- 예산표는 `Ⅳ`장 앞에 쪽나눔을 넣어 한 쪽에 담았습니다. 표가 쪽을 걸쳐 잘리면
  세로 병합한 `구분` 칸이 뒷장에서 빈칸으로 보입니다.
- docx-js는 `w:pBdr`의 자식을 `top→bottom→left→right` 순으로 내보내지만 OOXML 스키마는
  `top→left→bottom→right`를 요구합니다. `build.js` 끝에서 순서를 바로잡습니다.
