# 한국항공대학교 바이브 코딩 기반 학생창업 경진대회 과업지시서

원본(2026.07.20, AI 기반 학생창업 경진대회)을 **바이브 코딩(Vibe Coding)** 주제로 바꾸고,
일정을 `강의 → 멘토링 → 예선(서류) → 결승(PT)` 순서로 재구성한 개정본입니다.

> **이 문서는 확정본이 아닌 협의용 초안입니다.** 표지·머리말·`Ⅵ`장·예산표 아래에
> 미확정 문구를 넣어 두었습니다.

- 산출물: `한국항공대_바이브코딩_창업경진대회_과업지시서.docx` / `.pdf` (A4 8쪽, 작성일 2026.09.01)
- 생성 스크립트: `build.js` (docx-js)

## 다시 만들기

```bash
npm install docx
node build.js 한국항공대_바이브코딩_창업경진대회_과업지시서.docx
soffice --headless --convert-to pdf 한국항공대_바이브코딩_창업경진대회_과업지시서.docx
```

PDF 변환 시 맑은 고딕은 MS 독점 서체라 리눅스에 없습니다. `/etc/fonts/local.conf`에서
나눔바른고딕으로 대체하도록 걸어 두면 워드에서 열었을 때와 가장 비슷하게 나옵니다.

## 원본 대비 바뀐 점

### 1) 주제
AI 활용 아이템 → **바이브 코딩으로 직접 구현한 프로토타입** 기반 아이템.
기획서만 내는 대회가 아니라 **동작하는 결과물(데모 URL·저장소 링크)** 을 심사 대상으로 삼습니다.

### 2) 순서
원본은 `서류평가 → 특강 → 멘토링 → 본선`이었으나,
개정본은 요청대로 `특강 → 멘토링 → 예선(서류) → 결승(PT)` 입니다.
멘토링 대상은 서류 통과팀이 아니라 **특강 참가자·대회 참가 신청자 중 멘토링 신청 팀**입니다.

### 3) 일정 (특강은 지정일, 나머지는 매주 목요일)

| 단계 | 날짜 |
|---|---|
| 홍보 및 모집 | 9.7(월) ~ 9.25(금) |
| ① 창업 특강 (바이브 코딩 실습, 2시간) | **9.28(월)** — 발주처 지정일 |
| ② 1:1 창업 멘토링 | **10.8(목)** |
| 예선 접수 마감 | 10.13(화) 18:00 |
| ③ 예선 (서류평가) | **10.15(목)** |
| 예선 결과 발표 | 10.16(금) |
| ④ 결승 (PT) 및 시상식 | **10.22(목)** |
| 성과물 제출 | ~ 11.5(목) |

특강 9.28은 월요일이라 "수·목·금" 규칙의 예외이며, 이후 3개 행사는 모두 목요일입니다.

### 4) 예산 — 총액 10,000,000원 유지

| 구분 | 원본 | 개정 |
|---|---:|---:|
| 상금 및 부상 | 3,200,000 | 2,500,000 |
| 전문가 활용비 | 3,300,000 | 3,500,000 |
| 실습 환경비 (신설) | — | 1,500,000 |
| 홍보 및 인쇄비 | 700,000 | 700,000 |
| 행사 운영비 및 일반관리비 | 2,800,000 | 1,800,000 |
| **총 합계** | **10,000,000** | **10,000,000** |

확보 1,700,000 = 장려상 단가 20만→10만(700,000) + 결승 심사수당 50만→40만(300,000)
+ 참가자 기념품 제외(700,000).
배분 1,700,000 = 실습 환경비 신설·증액(1,200,000) + 멘토링비 팀당 10만→15만(500,000).

**전제 두 가지** — 원본에 근거가 없어 다음과 같이 잡았습니다.

- 기념품은 원본에서 `행사 운영비` 안에 묶여 있어 단가가 없었습니다. 60명 기준
  약 700,000원으로 보고 그만큼 덜어냈습니다.
- AI 코딩 도구는 **1인당 50,000원 × 30명**(멘토링 대상 10개 팀, 팀당 3인 기준)입니다.
  특강 참가자 전원(60명 내외)에게 유료 크레딧을 주면 3,000,000원이 되어 총액을 넘깁니다.

## 문서 서식

관공서 과업지시서 형식에 맞춰 편집했습니다.

- **표지** — 이중 테두리, 남색 제목 괘선, 문서정보 표(과업명·발주처·수행사·예산·작성일)
- **머리말/바닥글** — 머리말에 과업명, 바닥글에 쪽번호(표지 제외)
- **장 제목** — `Ⅰ~Ⅵ` 남색 바탕 흰 글씨 / **절 제목** — `가·나·다` 남색 글씨 + 밑줄
- **표** — 남색 머리행, 줄무늬 배경, `구분` 열 세로 병합, 합계행 강조
- **서체** — 맑은 고딕(`w:hint="eastAsia"` 지정, 본문 10.5pt / 줄간격 1.4)

### 만들 때 주의할 점

- 예산표는 `Ⅳ`장 앞에 쪽나눔을 넣어 한 쪽에 담았습니다. 표가 쪽을 걸쳐 잘리면
  세로 병합한 `구분` 칸이 뒷장에서 빈칸으로 보입니다.
- docx-js는 `w:pBdr`의 자식을 `top→bottom→left→right` 순으로 내보내지만 OOXML 스키마는
  `top→left→bottom→right`를 요구합니다. `build.js` 끝에서 순서를 바로잡습니다.

## 개정 이력

### 2026.09.03 — 예산 재배분 및 예선 범위 조정

- 결승 심사수당 500,000 → 400,000원 (VC 3인)
- 장려상 200,000 → 100,000원 상당 상품 × 7팀
- 참가자 기념품 항목 제외 (`마.` 행사 준비물, 운영비 세부내역)
- 1:1 멘토링비 팀당 100,000 → 150,000원, 멘토링 시간 40분 → 60분 이상
- AI 코딩 도구 이용료 1인당 50,000원 × 30명
- **예선은 사업계획서만 평가**하고 프로토타입은 결승에서 평가합니다.
  심사 항목 `프로토타입 구현 완성도` → `아이템 적합성`(배점 30% 유지)
- 미확정 문구를 표지·머리말·`Ⅵ`장·예산표 아래 4곳에 삽입
- 장(章)마다 쪽나눔을 넣어 한 쪽에 두 개의 대주제가 섞이지 않게 했습니다.
  `Ⅲ. 세부 과업 내용`은 분량상 2쪽에 걸칩니다.
