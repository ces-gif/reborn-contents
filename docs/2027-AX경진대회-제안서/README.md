## 확정된 숫자

- 총 예산 **30,000,000원** (부가가치세 포함)
- 시상금 **1등 300만 / 2등 200만 / 3등 100만** = 6,000,000원
- AI 연구 소프트웨어 사용료 **팀당 100만원 × 5팀** = 5,000,000원
- **본선 6개 팀**

## 설계상 정한 것 (협의 대상)

- 참가 10개 팀 · 50명 내외 → 중간 점검에서 본선 6개 팀 선발
  - 본선이 6팀이므로 그보다 많이 모아야 선발이 성립합니다. 10팀으로 잡았습니다.
- 참여 기업 4개사(회계법인·메디컬·유통·화장품), 기업당 과제 1건, 과제당 2~3개 팀
- 일정 — 1월 착수, 1.26 발대식, 2.24 본선. 2027년 설 연휴(2.5~2.8)를 피했습니다
- 일반관리비 5.06% · 이윤 10.0% — 지방계약법 시행규칙 제8조 한도(8%, 10%) 이내

## 숫자가 맞지 않는 지점

**AI 연구 소프트웨어 사용료는 5팀분(500만원)인데 본선은 6팀입니다.** 받은 숫자를
그대로 넣었고, 제안서 예산 쪽 각주와 「향후 협의 필요 사항」에 명시해 두었습니다.

6팀 전원에게 주려면 1,000,000원이 더 필요합니다. 선택지는 셋입니다.

1. 홍보·인쇄비(120만) 또는 행사 운영비(170만)에서 100만원을 옮긴다
2. 총액을 31,000,000원으로 올린다
3. 지원 대상을 5팀으로 두고, 중간 점검 상위 5팀에만 지급한다고 명시한다

`build_proposal.js` 에서 `5팀` 과 `5,000,000` 을 고치고 예산 표를 맞추면 됩니다.

## 예산 검산

직접비 23,600,000 → 일반관리비 1,193,727 → 이윤 2,479,000 → 총원가 27,272,727
→ 부가세 2,727,273 → **합계 30,000,000원**. 구성비 합도 100.0% 입니다.

## 만들 때 걸린 것

- 10쪽에 맞추려면 섹션마다 쪽 나눔을 넣는 방식으로는 안 됩니다. 섹션이 11개면
  11쪽이 됩니다. 「기대 효과」를 제안 개요 쪽에, 「보안 및 지식재산」을 참여 기업
  쪽에 붙여 두 쪽을 줄였습니다. 둘 다 그 자리가 내용상 더 맞습니다.
- 예산 쪽은 목록과 표가 같은 내용을 두 번 적고 있었습니다. 표 비고 칸에 있는
  항목은 목록에서 뺐습니다.
- 마지막 연락처 한 줄이 11쪽으로 넘어가 빈 쪽이 생겼습니다. 쪽 수는
  `pdfinfo` 로만 보면 알 수 없고, 렌더링해서 바닥을 봐야 합니다.
