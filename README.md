# 리본마켓 자동 콘텐츠 발행

구글 드라이브에 올라온 **그날 오전의 상품 사진**을 읽어서, 매일 **한국시간 낮 12시**에

- 인스타그램 스토리 사이즈(1080×1920) **카드뉴스 PNG** (상품마다 1장)
- 잘 팔릴 만한 **BEST 5 블로그 글** (네이버 붙여넣기용 HTML 포함)
- **카톡 오픈채팅 공지문** + **인스타 캡션**

을 만들어서 드라이브 `콘텐츠 발행` 폴더에 날짜별로 올리고, **카드뉴스를 인스타그램 스토리로 자동 게시**합니다.

깃허브 서버(Actions)에서 도는 작업이라 **내 컴퓨터가 꺼져 있어도 그대로 실행**됩니다.

**사진은 오전 11:30까지 올려주세요.** 30분 뒤인 12시에 그날 올라온 사진으로 콘텐츠가 만들어집니다.

## 카드뉴스 디자인 규칙 (고정)

기존 카톡 가격비교 카드의 톤앤매너를 스토리 비율로 옮긴 것입니다. 임의로 바꾸지 않습니다.

- 시그니처 오렌지 `#FD6F23` 통짜 가격 바 — 대각선 절단 없음
- 할인율은 회청색 `#72788E` 알약 뱃지에 오렌지 글씨
- **가격은 항상 두 줄**: `온라인 판매가`(취소선) → `리본마켓 초특가`(가장 큰 글씨)
- 좌상단에 **실제 리본마켓 로고 PNG** — 로고를 텍스트로 그리지 않습니다.
  로고 파일을 못 받으면 카드를 만들지 않고 멈춥니다 (잘못된 브랜딩 방지)
- 상하단 바가 화면 끝까지 닿는 **풀블리드**, 핵심 정보는 인스타 UI 안전영역(y 180~1790) 안쪽
- 상품명은 2줄까지 자동 크기 조절, 판매가는 뱃지를 침범하지 않도록 자동 축소

## 모델 비용 — 클로드 구독으로 돌리면 추가 비용이 없습니다

가격표 판독·제품 검색·블로그 작성에 쓰는 모델은 세 가지 중에 고릅니다.

| | **클로드 구독** (권장) | 제미나이 API | Claude API |
| --- | --- | --- | --- |
| 추가 비용 | **없음** — 쓰던 구독 그대로 | 무료 등급은 **하루 20회** | 선불 크레딧 |
| 필요한 것 | `CLAUDE_CODE_OAUTH_TOKEN` | `GEMINI_API_KEY` + 결제 | `ANTHROPIC_API_KEY` |
| 사진 판독 | ✅ | ✅ | ✅ |
| 웹 검색 | ✅ | ✅ 구글 검색 | ✅ |
| 데이터 학습 | 안 씀 | 무료 등급은 쓰일 수 있음 | 안 씀 |

**클로드 구독**은 코워크·클로드 코드에서 쓰시던 것과 같은 구독입니다. 깃허브 서버는
은성님 계정으로 로그인할 수 없어서 대신 **토큰 하나**를 넣어주면 됩니다.

### 클로드 구독으로 돌리기

1. 내 컴퓨터에서 클로드 코드를 열고 `claude setup-token` 을 실행합니다
2. 나오는 토큰을 복사합니다 (`sk-ant-oat...` 로 시작)
3. 저장소 → Settings → Secrets and variables → Actions → New repository secret
   - 이름: `CLAUDE_CODE_OAUTH_TOKEN`
   - 값: 복사한 토큰

이것만 넣으면 자동으로 구독 방식으로 돕니다. 제미나이 키는 그대로 둬도 되고 지워도 됩니다
(`model.provider: auto` 가 알아서 구독 → 제미나이 → Claude API 순으로 고릅니다).

> ⚠️ 이 토큰은 **은성님 클로드 계정으로 쓸 수 있는 열쇠**입니다. 시크릿에만 넣고
> 채팅·메모·코드에 붙여넣지 마세요. 사진 판독은 구독 사용량에서 나가는데,
> 하루 30장 정도는 아주 작은 양입니다.

`config/settings.yaml` 의 `model.provider` 를 `gemini` / `anthropic` / `auto` 로 바꾸면 됩니다.
키는 `GEMINI_API_KEY` 또는 `ANTHROPIC_API_KEY` 중 있는 쪽이 쓰입니다.

### 제미나이를 쓰신다면 — 사진이 하루 20장을 넘으면 결제를 켜야 합니다

제미나이 **무료 등급은 모델당 하루 20회 호출**까지입니다. 상품 하나당 1회를 쓰니
상품 10개쯤에서 한도가 찹니다. 한도를 넘으면 그 뒤 상품은 판독하지 못하고
리포트에 "판독하지 못한 묶음" 으로 남습니다. (클로드 구독으로 돌리면 이 한도가 없습니다)

풀려면 [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에서
**API 키가 붙어 있는 프로젝트에 결제를 켜면** 됩니다. 사진 판독 비용은
하루 수십 장 기준 몇십 원 수준입니다.

> 제미나이 **앱 구독(Google One AI)은 API 한도와 별개**입니다. 앱을 유료로 쓰셔도
> API 한도는 무료 등급 그대로입니다. 결제는 API 키가 있는 클라우드 프로젝트에 켜야 합니다.

## 채널별 자동화 수준

| 채널 | 자동화 | 비고 |
| --- | --- | --- |
| 드라이브 `콘텐츠 발행` | ✅ 완전 자동 | 날짜 폴더로 업로드 |
| 인스타그램 **스토리** | ✅ 완전 자동 | Instagram Graph API, 24시간 25건 제한 |
| 카카오톡 | 🔸 반자동 | '나에게 보내기'로 도착 → 오픈채팅방에 전달(탭 두 번) |
| 텔레그램 / 슬랙 / 디스코드 | ✅ 완전 자동 | 방을 옮기면 손 안 대도 됨 |
| 네이버 블로그 | 🔸 반자동 | **네이버가 블로그 글쓰기 API 를 종료했습니다.** 붙여넣기용 HTML 제공 (30초) |

네이버 블로그만 자동 게시가 불가능합니다 — 네이버 개발자센터가 블로그 오픈 API 를
[운영정책 위반을 이유로 종료](https://developers.naver.com/notice/article/7527)했고, 대체 공개 API 가 없습니다.
계정 자동 로그인으로 우회하는 방식은 네이버 이용약관 위반이라 만들지 않았습니다.
대신 `.html` 파일을 브라우저로 열어 전체 선택 → 복사 → 네이버 에디터에 붙여넣기만 하면
서식(글자크기 19, 소제목 볼드, 번호 목록, 비교표)이 그대로 살아납니다.

## 사진은 이렇게 올리시면 됩니다

한 상품당 둘 중 아무거나:

- **가격표 사진 1장 + 상품 사진 1장** — 순서는 상관없습니다
- **가격표와 상품이 한 장에 같이 나온 사진 1장**

묶는 기준은 **촬영 시각이 아니라 사진 내용**입니다. 사진을 한 장씩 먼저 읽어
가격표인지 상품인지, 그리고 그게 무슨 물건인지(가격표면 거기 적힌 상품명)를 파악한 뒤,
같은 물건끼리 묶습니다. 그래서 연달아 빠르게 찍으셔도 상품이 섞이지 않습니다.

**가격표만 찍힌 묶음은 카드뉴스를 만들지 않습니다.** 정보 전달용으로 보고 리포트에만 남깁니다.
카드뉴스 배경에는 반드시 상품이 보이는 사진을 씁니다 — 가격표 사진이 배경으로 올라가는 일은 없습니다.

## 안전장치 — 없는 말을 지어내지 않습니다

**가격** — 사진 속 가격표에 실제로 적힌 숫자만 씁니다. 못 읽으면 카드뉴스를 만들지 않고
`_data/리포트.md`의 확인 필요 목록에 올립니다. 정가 ≤ 할인가, 할인율 95% 초과 같은 이상한 값은
자동으로 걸러냅니다.

**상품 상태** — "미사용", "전시상품", "박스만 개봉", "새것 같은" 같은 표현은
**가격표에 그렇게 적혀 있을 때만** 씁니다. 사진이 깨끗해 보인다는 이유로 상태를 단정하지 않습니다.
근거 없는 상태 표현이 섞인 문장은 통째로 걷어냅니다 (단어만 오려내면 "박스만 개봉한 품" 같은
조각이 남기 때문입니다).

**제품 설명** — 상품명을 인터넷에서 찾아 그 제품이 무엇인지 한 줄로 붙입니다.
검색으로 그 모델을 특정하지 못하면 **아무 설명도 붙이지 않습니다** — 틀린 설명보다 빈칸이 낫습니다.
검색 결과에서 가격·재고·상품 상태는 가져오지 않습니다 (그건 매장 가격표만이 근거입니다).

**표현** — "중고"는 자동으로 "리퍼브"로 바꿉니다 (리본마켓은 검수를 마친 새 상품 매장).

## 시작하기

**Git 없이도 됩니다.** 저장소 우측 상단 `Code → Download ZIP` 으로 받아
압축을 풀고, 그 폴더의 **`setup.bat` 을 더블클릭**하세요.
파이썬이 없으면 마법사가 설치 페이지를 열어 안내합니다.

구글 드라이브 연결을 4단계로 안내하고,
실제로 연결되는지 검사한 뒤, 깃허브에 넣을 값까지 정리해 줍니다.

그 밖의 설정(인스타그램, 카카오톡 등)은 → **[docs/SETUP.md](docs/SETUP.md)**

로컬에서 손으로 돌려보고 싶을 때:

```bash
pip install -r requirements.txt
python scripts/fetch_logo.py                    # 드라이브에서 로고 받아 캐시
python scripts/run_daily.py --dry-run           # 업로드 없이 out/ 에만 생성
python scripts/run_daily.py --date 2026-08-21   # 특정 날짜분 다시 만들기
```

카드 디자인만 빠르게 확인:

```bash
python scripts/preview_card.py --photo 사진.jpg --name "쿠쿠 6인용 밥솥" \
  --desc "박스만 개봉한 미사용품" --orig 169000 --sale 89000 --out card.png
```

## 설정 바꾸기

`config/settings.yaml` 을 고치거나, 같은 이름의 **환경변수 / 깃허브 Variables** 로 덮어씁니다
(저장소를 안 고치고 바꾸고 싶을 때 유용합니다).

| 자주 바꾸는 값 | 키 | 기본값 |
| --- | --- | --- |
| 상품 사진 폴더 | `config/settings.yaml` 의 `drive.sources` | 리퍼 + 새상품 |
| 인스타 스토리 켜기/끄기 | `INSTAGRAM_ENABLED` | `true` |
| 하루 스토리 최대 장수 | `MAX_STORIES_PER_DAY` | `10` (인스타 제한 25) |
| 발행 폴더 이름 | `PUBLISH_FOLDER_NAME` | `콘텐츠 발행` |
| 하루 최대 카드 수 | `MAX_CARDS_PER_DAY` | `0` (제한 없음) |
| 같은 상품으로 묶는 간격 | `MAX_GAP_SECONDS` | `150`초 |
| BEST 몇 개 | `BEST_COUNT` | `5` |
| 매장명 | `STORE_NAME` | `리본마켓 평택점` |
