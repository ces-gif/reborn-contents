# 릴스 주제곡

릴스(숏츠) 뒤에 깔리는 매장 주제곡을 두는 곳입니다.

| 파일 | 매장 |
| --- | --- |
| `reborn-theme.mp3` | 리본마켓 평택점 |
| `fox-theme.mp3` | 여우마켓 일산점 |

## 넣는 법

파일 이름을 위 표대로 맞춰서 이 폴더에 넣고 커밋하면 **그날 릴스부터** 자동으로
깔립니다. 설정을 따로 고칠 필요는 없습니다 (`config/settings.yaml` 의
`stores[].instagram.reel_music` 가 이미 이 경로를 가리킵니다).

- 곡이 영상보다 짧으면 **반복 재생**하고, 길면 영상 길이에서 자릅니다.
- 끝 0.6초는 **페이드아웃** 합니다. 뚝 끊기지 않게.
- 파일이 없으면 예전처럼 **무음**으로 만듭니다. 음악 때문에 그날 릴스가
  통째로 안 나오는 일은 없습니다.

## 길이

릴스는 보통 10~25초입니다 (카드 장당 0.8초 + 표지). 20~30초짜리 한 곡이면
반복 없이 대부분의 날을 덮습니다.

## 저작권

매장 계정에 올리는 영상이라 **상업적 사용이 가능한 음원**이어야 합니다.
직접 만든 곡이나, 상업 이용이 허용된 생성 음원만 넣어 주세요.
