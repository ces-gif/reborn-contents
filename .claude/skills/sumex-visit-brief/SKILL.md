# SUMEX 방문 준비

방문 전에 세 가지를 확정한다. **몇 장 들고 가나 / 몇 시까지 가야 하나 / 무엇을 챙기나.**

## 절차

```bash
cd SUMEX && export PYTHONPATH=src
```

### 여러 곳을 도는 날

```bash
python3 -m sumex.cli visit 세종스포츠 무척나은 서울점프 구리센트럴
```

출력에 들어 있는 것:
- **방문 순서** — 시간 창이 좁은 곳을 앞에, 서울권 밖을 뒤에 자동 배치
- 각 병원의 **서류 종류와 매수**
- **시간 제약** (납품 가능 시간, 냉장·냉동 컷오프, 담당 부재 시각, 주차장 운영)
- **총 준비할 서류 매수** — 이 숫자만큼 미리 뽑아 간다
- **동선 메모**

### 한 곳만 갈 때

```bash
python3 -m sumex.cli checklist 세종스포츠          # 터미널 출력
python3 -m sumex.cli checklist 세종스포츠 --md -o /tmp/세종.md   # 파일로
```

### 케이스 커버가 있는 날

```bash
python3 -m sumex.cli casecover 세종스포츠
```

7축(카메라·빛·물·칼·에너지·고정·봉합) 점검표 + 그 병원에 들어가는 품목 목록.
**예비 광케이블은 항상 동행**한다.

## 놓치면 그날이 무산되는 것

이 항목들은 출력에 `★` 로 표시된다. 사용자에게 **반드시 그대로 전달**한다.

- **분당서울대** — 09:00~11:00 / 13:00~16:00 창을 놓치면 그날 납품 불가.
  냉장·냉동은 14:00 이전. 쇼핑백 말고 흰색 봉투.
- **고대 구로·안암** — 수술방 마감 시 16:00 이전 도착
- **구리센트럴** — 16:45 이후 담당 부재 가능
- **서울척** — 주차장 평일 17:00까지. 수술실 14층 / 총무팀 B2 (층 이동 시간)
- **신촌세브란스** — 목요일 방문 자제 요청

## 방문 후

당일 저녁에 결과를 정리한다. 기억이 선명할 때가 아니면 남지 않는다.
확정한 사실이 있으면 `SUMEX/data/hospitals.yaml` 을 바로 고친다 —
체크리스트·방문계획·대시보드가 전부 따라 바뀐다.

새로 알게 된 것이 `sumex audit` 의 '확인 필요' 목록에 있던 항목이면
해당 `open:` 줄을 지우고, 후속조치였다면 `python3 -m sumex.cli task done T-0XX`.
