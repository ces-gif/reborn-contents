# SUMEX 납품 서류 생성

병원마다 서류 규칙이 **전부 다르다.** 매수를 틀리면 다시 출력하러 나가야 하고,
도장이 하나 빠지면 서류가 반려되어 다음 달 마감으로 밀린다.
그래서 서류를 만들 때는 **항상 체크리스트를 함께 낸다.**

## 절차

### 1. 병원과 품목을 확인한다

사용자가 병원명과 품목·수량·단가를 주지 않았으면 물어본다. 단가를 모르면
0으로 두고 만든 뒤 "단가는 비워 두었으니 채우세요"라고 알린다.

거래처 이름은 약칭으로도 찾는다: `세종스포츠`, `서울척`, `무척나은`, `적십자`, `고대`

```bash
cd SUMEX && export PYTHONPATH=src
python3 -m sumex.cli hospitals          # 전체 목록
python3 -m sumex.cli hospital 서울척     # 이 병원의 규칙 전체
```

### 2. 서류 종류를 고른다

| 서류 | 언제 |
|---|---|
| 거래명세서 | 실제 납품·사용분 확정 (기본) |
| 가납서 | 정식 발주 전 물건 선투입 |
| 선납서 | 환자별 사용분 발생 시 (환자명·코드 필수) |
| 견적서 | 장비 제안·수리비 청구 |

병원의 기본 서류 종류는 `sumex hospital <이름>` 의 `doc_type` 에 있다.
서울의료원·고대는 **선납서**가 기본이다.

### 3. 만든다

```bash
python3 -m sumex.cli doc 세종스포츠 \
  --items "ICONIX 1.7T x 3 @ 320000; ICONIX 1 NEEDLES x 2 @ 33350" \
  --suffix 수술방
```

- 품목이 많으면 CSV: `--items items.csv` (열: 코드,상품명,포장단위,수량,단가)
- 서류 종류: `--type 가납서` / `--type 선납서`
- 날짜 지정: `--date 2026-08-14`
- 파일명 뒤에 붙일 말: `--suffix 수술방` 또는 간납사명

견적서는 그룹으로 묶는다:

```yaml
# quote.yaml
subject: 1788 관절경 타워
groups:
  - group: 1788 VIDEO CAMERA SYSTEM
    items:
      - { code: 1788-010-000, name: 1788 Camera Control Unit, qty: 1, price: 0 }
```
```bash
python3 -m sumex.cli quote 호수병원 --spec quote.yaml
```

### 4. 체크리스트를 함께 전달한다

`doc` 명령은 체크리스트를 자동으로 함께 출력한다. 그 내용을 사용자에게
**그대로 전달한다.** 특히 이 세 가지는 빠뜨리지 않는다.

- **매수** — 몇 장 뽑아야 하는가
- **도장** — 어디에 몇 종을 찍는가
- **배부처** — 각 부를 어디에 두고 오는가

## 반드시 확인할 것

- **환자 1명당 1건**으로 쪼개야 하는 병원이 있다 (청담리온). 묶으면 안 된다.
- **간납사가 서류를 만들어 주는** 병원이 있다 (노원을지-토탈메디칼,
  성남시의료원-파마블루, 구리센트럴-아네스). 이 경우 우리가 만든 서류가 아니라
  간납사가 돌려준 서류로 납품한다. 사용자에게 이 점을 알린다.
- **간납사 사이트에서 출력**해야 하는 병원이 있다 (신촌세브란스 SSCM,
  서울척 지이아이글로벌). 이때는 xlsx 생성이 아니라 사이트 입력을 안내한다.
- 매수가 `?` 로 나오면 아직 확인되지 않은 병원이다. 기본 4장을 준비하고
  현장에서 확정하라고 안내한다.

## 금액 규칙

단가·금액은 **VAT 포함가**로 넣는다.
공급가액 = 합계 ÷ 1.1, 부가세 = 합계 − 공급가액. 코드가 알아서 계산한다.

## 개인정보

`data/private/company.yaml` 이 없으면 사업자등록번호·대표자·계좌가
`(비공개)` 로 찍힌다. 그대로 두고 사용자에게 알린다 —
`python3 scripts/bootstrap_private_data.py` 로 채울 수 있다.

거래처 담당자 실명·연락처를 공개 저장소 파일에 쓰지 않는다.

## 출력 위치

`SUMEX/out/서류/SUMEX {서류종류}({품목})_{YYMMDD}[_{접미사}].xlsx`

생성 후 `SendUserFile` 로 사용자에게 파일을 보낸다.
