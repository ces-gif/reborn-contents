# SUMEX 업무 스케줄

마감일을 놓치면 **대금 지급이 밀린다.** 이 스킬의 존재 이유다.

## 절차

```bash
cd SUMEX && export PYTHONPATH=src
```

### 아침 브리핑

```bash
python3 -m sumex.cli today
```

들어 있는 것:
- 휴무일·연휴 경고 (다음 영업일이 이틀 이상 뒤면 "연휴 전에 마감할 것" 안내)
- **월 마감 기간 경고** (매월 1~3일)
- 기한 지난 후속조치 (며칠 지났는지 함께)
- 오늘의 반복 업무
- **회신 없이 3일 이상 지난 수리 건** — 병원이 묻기 전에 먼저 연락할 대상
- 서류 규칙이 아직 비어 있는 거래처

### 주간 / 월간

```bash
python3 -m sumex.cli week              # 요일별, 휴무 표시, 동선 메모
python3 -m sumex.cli month 2026-09     # 병원별 마감일을 실제 날짜로 환산
```

### 할 일 관리

```bash
python3 -m sumex.cli task list --pri 최상
python3 -m sumex.cli task list --hospital 서울척
python3 -m sumex.cli task done T-004
python3 -m sumex.cli task doing T-017
```

상태는 `data/tasks.yaml` 에 그대로 반영된다 (주석·배치 유지).

### 구글 캘린더

```bash
python3 -m sumex.cli ics --month 2026-09
```

→ 구글 캘린더 → 설정 → 가져오기 및 내보내기 → 가져오기.
중요도 '최상' 항목에는 하루 전 알림이 붙는다.

Google Calendar MCP 도구가 있으면 개별 일정을 직접 등록해도 된다.
그 경우 `sumex month` 결과를 근거로 삼고, **마감 하루 전** 알림을 건다.

## 월 마감 — 병원별로 규칙이 다르다

| 시점 | 병원 | 무엇 |
|---|---|---|
| 매월 1일 | 노원을지 | 토탈메디칼 사이트에서 이달 마감 기간 확인 (**알림이 안 온다**) |
| 매월 1~3일 | 청담리온 | 이 기간을 넘기면 간납사에서 계속 전화가 온다 |
| 매월 초 | 고대 | 사이트 마감 일정 공지 확인 |
| 매월 초 | 세종스포츠 | 도장 받은 명세서 스캔본 + 간납금액 명세서 메일 |
| 매월 초 | 하늘 | 구매과에 매출원장 전달 |
| 월 2회 | 성남시의료원 | 파마블루 발송 명세서 수령·배부 |
| 매월 말 | 하늘 | 구매과와 일정 잡아 직접 방문 카드 수금 |

**고대병원 마감의 하드 룰**: 거래명세서 수량 총합 == 선납서 수량 총합.
두 값이 같아야 통과된다. 선납서를 한 장이라도 분실하면 마감을 도와주지 않는다.
→ 선납서는 발행 즉시 스캔해 둔다.

## 새 할 일을 추가할 때

`SUMEX/data/tasks.yaml` 의 `backlog:` 에 한 줄 추가한다.

```yaml
  - { id: T-050, cat: 확인, hospital: seoul-spine, due: 2026-09-05, pri: 상, status: todo,
      title: "...", note: "..." }
```

`hospital` 은 `data/hospitals.yaml` 의 id 를 쓴다. 실명·연락처는 넣지 않는다.

## 반복 업무를 추가할 때

`recurring:` 에 추가한다. `when` 은 한국어로 쓴다 —
`매월 1~3일`, `매월 1일`, `매주 월요일`, `매월 말`, `월초` 를 해석한다.
