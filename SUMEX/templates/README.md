# templates — 회사 실양식 xlsx 를 두는 곳

`.gitignore` 로 `*.xlsx` 가 제외되어 있다. 로고·사업자등록번호·결제계좌가
들어 있어서 공개 저장소에 올리지 않는다.

## 넣으면 좋은 파일

| 파일명 | 어디서 |
|---|---|
| `거래명세서.xlsx` | 실제 발행한 거래명세서 아무거나 하나 (품목만 지우고) |
| `가납서.xlsx` | 없으면 거래명세서 양식을 그대로 쓴다 |
| `선납서.xlsx` | 없으면 거래명세서 양식을 그대로 쓴다 |
| `데모인수증.xlsx` | 스트라이커 배포본 `KQF-OPC-009-F Korea Demo Receipt Form` |

## 넣으면 무엇이 달라지나

**넣으면** — 그 파일을 열어 **값만 바꾼다.** 로고·서식·인쇄 설정·셀 병합이
그대로 유지되므로 병원에 그대로 낼 수 있다.

**안 넣으면** — 코드가 같은 셀 좌표로 레이아웃을 새로 그린다. 항목과 계산은
동일하지만 로고가 없고 서식이 단순하다. 내부 확인용으로는 충분하다.

## 좌표

거래명세서는 아래 좌표를 쓴다 (실제 자사 양식에서 확인한 값).

| 셀 | 내용 |
|---|---|
| A2 | "거 래 명 세 서" |
| A7 (A7:C7 병합) | 날짜 |
| A9 (A9:C9 병합) | 병원명 |
| D6 / D7 / D8 / D9 | 사업자등록번호 / 상호명 / 주소 / 대표자 |
| 11행 | NO · 코드 · 상품명 · 포장단위 · 수량 · 단가 · 금액 |
| 12~37행 | 품목 (금액 = `=E{행}*F{행}`) |
| F38 | `=SUM(G12:G37)` — VAT 포함 합계 |
| G39 / G40 / G41 | 공급가액 `=F38/1.1` / 부가세 / 합계 |
| C42 | 결제계좌 |

시트 이름은 `견적서 (2)` 다 (실제 파일이 그렇다). 다르면 첫 번째 시트를 쓴다.

좌표가 바뀌면 `data/doc_types.yaml` 과 `src/sumex/docs.py` 를 함께 고친다.

## 데모인수증

스트라이커 양식은 배포본마다 셀 위치가 달라질 수 있어, 코드가 **라벨을 찾아
그 오른쪽에 값을 넣는** 방식으로 채운다. 라벨: `병원명` `요양기관번호` `병원과`
`의사명` `출고일` `회수일` `담당자` `부서 및 대리점`
