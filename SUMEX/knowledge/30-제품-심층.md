## 1. 영상 시스템 — 1688 AIM 4K / 1788 Platform

### 의학

카메라 헤드와 스코프를 바꿔 끼우는 것만으로 서로 다른 과에 투입된다.
이것이 이 제품의 영업적 위력이자, 우리가 여러 과를 동시에 공략할 수 있는 근거다.

| 술식 | 팽창 매체 | 대표 수술 | 스코프 | 과 |
|---|---|---|---|---|
| 관절경 | 생리식염수(펌프) | 회전근개 봉합, 반월상연골, ACL 재건 | 4.0mm 30°/70° | OS |
| 복강경 | CO2 가스(인슈플레이터) | 담낭·충수·대장절제, 탈장, 자궁적출 | 10mm 0°/30° | GS, 산부인과 |
| 흉강경 | 폐 허탈(단일폐환기) | 폐엽절제, 종격동 종양 | 10mm 30° | TS |

> 같은 1788 플랫폼이 서울적십자에는 복강경 구성으로, 서울대어린이병원에는
> 관절경 구성으로 들어간다. **같은 제품을 서로 다른 언어로 설명할 수 있어야 한다.**
> 일반외과 교수에게는 "담도 손상 예방과 문합부 혈류 평가"를,
> 정형외과 교수에게는 "관절강 내 어두운 부위의 노이즈 없는 밝기"를 말한다.

**AIM (Advanced Imaging Modalities)** — 근적외선 형광 영상 기능군.
인도시아닌그린(ICG)을 정맥 주사한 뒤 근적외선을 조사하면 혈류가 있는 조직이 형광을 낸다.

| 용도 | 설명 | 설득 대상 |
|---|---|---|
| 관류 평가 | 대장 문합 전 혈류 확인 → 누출 감소 | 대장항문외과 |
| 담도 조영 | 담낭절제 시 담도 주행 확인 → 손상 예방 | 간담췌·일반외과 |
| 림프 지도화 | 감시림프절 식별 | 유방·부인암 |
| 조직 관류·판막 | 피판 생존 판단 | 성형외과 |

**현장 한 문장**

> "1688은 4K에 형광을 넣은 첫 세대이고, 1788은 그 형광을 다시 설계한 세대입니다.
> 어두운 데서 보이느냐, 경계가 또렷하냐가 실제로 달라집니다."

1788 은 형광 영상의 경계 구분(delineation)을 재설계했고, 어두운 부위를 보정하는
Tone Mode 와 32인치 4K OLED 모니터(자발광, 높은 명암비·깊은 블랙)를 함께 제공한다.

**카메라 헤드 내부** (서비스 절차서 TSI10398 의 분해 순서에서 구조가 드러난다)

1. 케이블 분리 — 잼 너트를 풀고 버튼 케이블과 CMOS KEL 케이블 분리
2. 헤드 개방 — 캠락을 반시계로 돌려 전·후방 인클로저 잠금 해제
3. 전·후방 인클로저 분리
4. 프리즘 분리 — 프리즘 브래킷·히트 브래킷 스크류(T7 Torx) 제거

| 부품 | 역할 | 고장 시 증상 |
|---|---|---|
| 프리즘 + CMOS | 입사광을 R/G/B 로 분광해 결상 | 노 픽처, 색 이상, 핫/콜드 픽셀, 센서 시프트, 스미어 |
| KEL 케이블 | 프리즘–케이블 간 미세 신호 전달 | 간헐적 영상 끊김 |
| 카메라 케이블(인증칩 내장) | 신호·전원 + 정품 인증 | 인증 실패 시 **E-05** |
| 버튼 키패드 / 4-button 보드 | 화이트밸런스·광원 토글 | 버튼 무반응 |
| 전·후방 인클로저 + O-ring | 밀폐(멸균·침수 대응) | **누수** — 김서림, 부식 |

> **왜 누수가 치명적인가**
> 카메라 헤드는 매 케이스마다 세척·소독·멸균을 거친다. O-ring 이나 스트레인
> 릴리프가 손상되면 세척액이 들어가 프리즘에 김이 서리거나 커넥터 핀이 부식된다.
> 부식된 커넥터는 간헐적 영상 끊김으로 이어지고, 이는 **수술 중** 발생하기 때문에
> 신뢰를 크게 잃는다.
> **병원 중앙공급실(CSSD)에 소커 캡 체결과 침지 절차를 교육하는 것이 클레임 예방의 8할이다.**

## 2. 대골 파워툴 — System 9

> "Built on trust. Empowering you." — 1983년 OP 90 에서 시작해 S2000(1991),
> System 4(1998), 5(2002), 6(2006), 7(2012), 8(2017)을 거쳐 2023년 System 9 로
> 이어지는 **40년의 계보**. Stryker 라는 브랜드의 원점이 파워툴이다.

### 의학 — 핸드피스와 적응증

| 핸드피스 | 기능 | 대표 적응증 |
|---|---|---|
| Sagittal saw | 좌우 진동 절삭 | 인공슬관절 대퇴·경골 절삭 |
| Reciprocating saw | 왕복 절삭 | 좁은 공간 절골, 재치환 시 임플란트 분리 |
| Sternum saw | 흉골 절개 전용 | 개흉 심장수술 |
| SABO saw | 소형 사지 절삭 | 족부·수부·소아 |
| Precision oscillating tip saw | **팁만 진동** | 연부조직 손상 최소화 |
| Single / Dual trigger rotary drill | 드릴링·리밍 | 외상 골절 고정, 치환 준비 |
| Cordless driver (CD NXT) + POWEReam | 무선 드릴·리머, 고토크 | 난이도 높은 리밍 |
| EZout | 비구컵 제거 동력화 | 인공고관절 재치환 |

**왜 파워툴이 임상 결과에 영향을 주는가**

- **열 손상** — 드릴링 마찰열이 47℃를 넘기면 골세포가 괴사한다.
  회전수·토크 제어와 관류가 중요한 이유.
- **절삭면 평탄도** — 고르지 않으면 임플란트–골 접촉이 나빠지고 초기 안정성이 떨어진다.
- **연부조직 보호** — Precision oscillating tip saw 처럼 팁만 진동하면 손상이 적다.
- **수술 시간** — EZout 은 재치환 비구컵 제거 시간을 크게 줄인다. 시간 단축은 감염률과 직결.

### 공학 — 6가지 설계 포인트

| 요소 | 내용 | 현장 이점 |
|---|---|---|
| Twist-lock 인터페이스 | 핸드피스–배터리 결합부, 촉각·시각 피드백 | 조립 속도, 결합 오류 감소 |
| 배터리 인디케이터 | 더 밝고 위치 재배치, 접점 개선 | 수술 중 잔량 오판 방지 |
| IPX 9 + 아노다이징 코팅 | 고압수·강한 세정제 내성 | 반복 세척·멸균에서 수명 연장 |
| 안전 포켓 개선 | 우발적 작동 방지 | 안전사고 예방 |
| 인체공학 핸들 | 균형·압점 감소 | 장시간 절삭 피로 감소 |
| **무선 충전기 (업계 최초)** | 블루랩 위로도 충전, 이물 감지 | **멸균 상태를 유지한 채 충전** |

**배터리 인디케이터 판독법 — 수술실 교육 필수**

| 표시 | 의미 | 조치 |
|---|---|---|
| 녹색 상시 | 완전 충전 | 사용 가능 |
| **황색 점멸** | 저전압 — **약 2분 미만** 절삭 가능 | 즉시 예비 배터리 준비 |
| 황색 상시 | 완전 방전 또는 오류 | 교체, 반복 시 접점·하우징 점검 |

**아세틱(Aseptic) 배터리 시스템** — 배터리는 전자부품이라 직접 멸균이 어렵다.
비멸균 배터리를 멸균 하우징에 옮겨 담는 구조를 쓴다.

| 구성 | 대(Large) | 소(Small) |
|---|---|---|
| 비멸균 배터리 | 9126-110-000 | 9222-110-000 |
| 아세틱 배터리 하우징 | 9126-120-000 | 9222-120-000 |
| 트랜스퍼 실드 | 9126-130-000 | 9222-130-000 |

> **무선 충전기가 바꾸는 워크플로**: 기존에는 멸균 후 잔량이 부족하면 다시

## 3. 신경외과·척추 파워 — CORE 2 + HSD

### 의학 — High Speed Drill 이 필요한 수술

뼈를 얇게 갈아내되 **바로 밑의 신경·경막·혈관은 다치지 않아야** 하는 상황.
대골 파워툴과는 요구 성능이 완전히 다르다.

| 수술 | 드릴이 하는 일 | 위험 |
|---|---|---|
| 개두술 | 두개골 절개·천공 | 경막 손상 |
| 추궁절제술 | 척추 후궁을 갈아 신경 감압 | 경막·신경근 손상 |
| ACDF | 추간판·골극 제거 | 척수·척추동맥 손상 |
| 종양 절제 | 두개저 골 삭제 | 뇌신경 손상 |

**요구 성능 4가지**
1. 고회전·저진동 — 미세 삭제를 위해 높은 RPM, 진동이 크면 제어 불가
2. 관류 동시 제공 — 열 발생 억제로 신경 열손상 방지
3. 정교한 그립·시야 — 현미경 아래 좁은 술야에서 손 떨림이 결과가 된다
4. **버(Burr) 다양성** — 라운드·매치스틱·**다이아몬드**.
   다이아몬드 버는 절삭력이 낮은 대신 연부조직 손상 위험이 적어 **경막 근처**에 쓴다

### 공학 — CORE 2 콘솔

| 항목 | 사양 |
|---|---|
| 포트 | 모터/핸드피스 3, 풋스위치 2, 관류 카세트 1 |
| 동시 구동 | 드릴 2개 + 관류 + Bone Mill |
| I.D. Touch | 핸드피스별 토크·촉감·정밀도 맞춤 설정 |
| 프리셋 | **100개 저장·전송** |
| 디스플레이 | 7인치 컬러 터치스크린 |
| 콘솔 품번 | 5400-052-000 |

> **왜 프리셋 100개가 영업 포인트인가**
> 대학병원 신경외과에는 교수별로 선호하는 회전수·촉감이 다르다. 프리셋을 교수별로
> 저장해두면 "내 세팅이 그대로 있는 콘솔"이 되어 전환 저항이 사라진다.
> 반대로 프리셋을 설정해주지 않으면 아무리 좋은 콘솔도 "손에 안 맞는다"는 평가를 받는다.
> **설치 당일 프리셋 세팅이 계약의 마지막 단계다.**

### 영업 — HSD 세트 딜

**잘 팔리는 조건**
- 신규 개원 또는 신경외과 신설 (연세무척나은 NS CORE 2 HSD set, 2025.5)
- 기존 콘솔의 노후·단종 — 어태치먼트 수리 불가 시점이 최적 타이밍
- 척추 내시경·미세침습 술식 확대
- 교수 영입 — 이전 병원에서 쓰던 시스템을 요청하는 경우가 많다

**NS 계정 공략 순서**
1. 과장·주임교수 파악 — 척추 중심인지 뇌 중심인지에 따라 버·어태치먼트가 다르다
2. 현재 콘솔·핸드피스 조사 — 브랜드, 연식, 최근 수리 이력
3. 시연 — **실제 사용할 교수의 손에 쥐여주는 것**이 유일하게 유효한 시연
4. 세트 구성 제안 — 콘솔 + 핸드피스 + 어태치먼트 + 버 소모품 + 풋스위치
5. 소모품 정착 — 버는 반복 구매 품목. 규격별 사용량 파악 후 선제 재고
6. 타 과 확산 — 같은 CORE 2 콘솔은 ENT·OS 셰이버로도 확장 가능

## 4. 피부봉합 — Zip

> 우리 포트폴리오에서 가장 **"설명해서 파는"** 제품이며, 따라서 가장 깊이 알아야 한다.

### 의학

| 층 | 두께 | 봉합 담당 |
|---|---|---|
| 표피 (Epidermis) | 0.1~1.4mm | **Zip 이 담당** |
| 진피 (Dermis) | 0.5~3mm | 집도의가 흡수성 봉합사로 |
| 피하조직 | 개인차 | 집도의 |
| 근막 | — | 집도의 |

> **반드시 정확히 말해야 하는 한 문장**
> "Zip 은 표피 봉합만 대체합니다. 진피와 피하조직은 선생님이 그대로 봉합하셔야 합니다."
>
> 이 전제를 빼고 팔면 반드시 실패한다. 심부층 봉합이 느슨하면 피부 간격이
> 벌어져 Zip 이 제 성능을 내지 못한다.

**조직 관류(Tissue perfusion)** — 창상 치유의 가장 중요한 인자 중 하나.
스테이플은 점 하중으로 국소 허혈과 창백(blanching)을 일으킬 수 있다.
Zip 은 폐쇄력을 균일하게 분산시킨다. 족관절 전치환술 임상연구에서 Zip 은
스테이플 대비 유의하게 높은 조직 관류를 보였다 (p<0.001).

고령·얇은 피부 환자에서 **오히려 유리하다.** 넓은 접착 면적으로 단위 면적당
힘이 낮아 피부 손상 위험이 적다.

### 적용 7단계

1. **라이너 #1 제거** — 장갑이 접착면에 닿지 않도록
2. **정렬·거치** — 절개선의 길이·폭 중앙. 한 번 피부에 닿으면 들어 올리지 않는다
   (들었으면 새 제품). 상단으로 스트랩 1~2개가 넘어가도록
3. **접착 적용** — 라이너 #2를 몇 cm씩 벗기며 진행. **늘이지 말고 "걸어가듯" 눕힌다.**
   곡선은 방향을 조향하며 밀착
4. **폐쇄** — 락 박스를 잡고 스트랩 하나씩 2~3클릭으로 창연을 맞춘다.
   한쪽 끝에서 시작해 순차 진행. **과도하게 조이지 않는다**
5. (선택) **접착제 병용** — 필수 아님. 도포 후 60초 경화 대기
6. **마무리** — 스트랩을 짧게 다듬는다. 드레싱 접착제·테이프가 Zip 본체에 직접 닿지 않게
7. **착용 기간** — 표준 14일, 최대 30일

**적용 전 확인**: 접착제 알레르기 여부 / 체모 제거, 피부 건조 / 사이즈와 위치
(절개창이 끝 스트랩을 넘어가면 안 됨) / 최소 길이는 스트랩 3개 /
**무릎 정중 절개는 45~60도 굴곡 상태에서 적용**

**제거**: 절개선을 따라 천천히. 창상에서 멀어지는 방향으로 당기지 않는다.
여러 조각으로 부서질 수 있으며 정상이다.

> **신규 고객 첫 케이스에서 반드시 할 일**: 제거 시점에도 입회한다.
> 적용은 잘 됐는데 제거를 서툴게 해서 인상이 나빠지는 사례가 많다.
> 피부 벗겨짐 우려가 있으면 베이비 오일이나 의료용 점착제 제거제를 쓴다.

5. **팔로우업** — 첫 몇 케이스는 **제거 시점까지** 팔로우한다

## 5. 스포츠메디슨 — ICONIX All-Suture Anchor

### 의학 — 왜 all-suture 인가

전통적인 봉합 앵커는 금속이나 PEEK 나사를 뼈에 박는다. 문제는 **뼈를 그만큼
파낸다**는 것이다. 회전근개 재파열로 재수술을 하면 이전 앵커 자리가 비어 있어
새 앵커를 박을 자리를 찾기 어렵다. 골다공증 환자에서는 애초에 나사가 잘 안 물린다.

All-suture anchor 는 **봉합사 자체가 뼈 구멍 안에서 뭉쳐 부풀며** 고정된다.
필요한 구멍이 훨씬 작아 골 소실이 적고, 골질이 나빠도 넓은 접촉면으로 힘을 분산한다.

| 부위 | 술식 |
|---|---|
| 어깨 | 회전근개 봉합, 관절와순 봉합(Bankart·SLAP), 이두건 고정 |
| 어깨(불안정성) | 전방·후방 불안정성 봉합 — 작은 직경(1.4mm)이 유리 |
| 무릎 | 반월상연골판 뿌리 봉합, 내측측부인대 보강 |
| 족부·족관절 | 아킬레스건 부착부, 인대 재건 — 골 보존이 특히 중요 |
| 고관절 | 관절와순 봉합 — 비구연 골 두께가 얇아 소형 앵커 선호 |

### 공학

| ICONIX Speed | **셀프펀칭** — 별도 드릴링 없이 배치 |

1. **골 보존** — "1.4mm면 재수술 여지를 남깁니다"
2. **골질 대응** — "골다공증 상완골두에서 나사식보다 안정적입니다"
3. **시간** — "Speed 는 펀칭 단계가 빠집니다"

이 세 가지 외의 이야기는 대개 Arthrex 의 브랜드 파워 앞에서 힘을 잃는다.

**Arthrex 와 앵커 대 앵커 정면 승부를 하지 않는다.** 국내 어깨 관절경 시장에서
Arthrex 는 사실상 표준이며, 레지던트·펠로우 교육 단계부터 손에 익어 있다.

### AlphaVent — 함께 제안하는 하드바디 앵커

## 6. 개인보호 — T7 / T7plus (구 Flyte)

### 의학 — 왜 헬멧을 쓰는가

인공관절 수술은 시간이 길고 골편·혈액·체액 비산이 많다. 헬멧 시스템은 두 가지를
동시에 한다.

1. **술자 보호** — 혈액매개 병원체와 비말·에어로졸 차단. 구조적으로 PAPR 과 유사
2. **환자 보호** — 술자의 피부 낙설·비말이 창상에 떨어지는 것을 차단.
   인공관절 감염(PJI)은 재수술과 막대한 비용을 유발하므로 예방 가치가 크다

### 공학

| 항목 | 내용 |
|---|---|
| 무게·소음 | Stryker 헬멧 중 가장 가볍고 조용. 이전 모델 대비 **소음 40% 감소** |
| 배터리 | 수명 연장 |
| 조절 | 높이·폭 듀얼 조절 노브 |
| T7plus 후드·토가 | 통기성 신소재 + **AAMI Level 4** |

> **AAMI Level 4 가 무슨 뜻인가**: 수술용 가운·드레이프의 액체 방어 등급 중
> 최고 수준으로, **바이러스 침투 저항**까지 요구한다. Level 1~3 은 액체 저항만
> 평가한다. 감염관리팀과 대화할 때 이 한 단어가 대화의 격을 바꾼다.

### 영업

1. **소모품 구조가 핵심** — 본체는 내구재지만 후드·토가는 케이스마다 소모된다.
   헬멧 도입 = 지속 매출
2. **구매 결정 주체가 다르다** — 임플란트는 집도의가, 헬멧·후드는
   **수술실 간호팀·감염관리팀·구매팀**이 실질적 결정권을 갖는 경우가 많다.
   2025년 고대안암 Flyte Helmet 발주도 OR 간호사와의 관계에서 시작됐다
3. **착용감이 전부다** — 무게·소음·시야·김서림은 써봐야 안다. **실물 착용 시연 필수**
4. **감염관리 지표와 연결** — 인공관절 감염률·재입원율 데이터에 관심 있는 병원에 소구력
5. **교체 주기 관리** — 배터리·필터·후드 재고를 선제적으로 채우는 것이 재주문의 실체

## 7. 재고·물류 원칙

1. **케이스 기반 예측** — 병원별 주간 수술 스케줄을 확보해 필요 품목을 역산
2. **사이즈 스펙트럼 확보** — 앵커·스크류는 상하 한 단계씩 여유

4. **사용 기록 즉시 입력** — **사용 후 미청구는 곧 매출 누락**
5. **대차·백업 장비 운영** — 다운타임은 신뢰를 잃는 가장 빠른 길
