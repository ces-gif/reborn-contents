# 서류 업무 총람

> **첫 주에 반드시 읽을 문서.** 나머지는 몰라도 시간이 해결하지만,
> 서류를 틀리면 그 주에 바로 사고가 난다.
>
> 병원마다 서류 처리 방법이 **전부 다르다.** 매수도, 도장 유무도,
> 제출처도, 마감일도 다르다. 외우려 하지 말고 매번 확인하고 나가라.
>
> ```bash
> sumex checklist 세종스포츠     # 출력해서 차량에 비치
> sumex visit 세종스포츠 무척나은  # 여러 곳 돌 때 총 매수·순서
> ```

---

## 1. 서류가 하는 일

돈의 흐름은 이렇다.

```
제조사(Stryker) → 수입/총판 → SUMEX → 병원 → 건강보험공단·환자
```

우리가 물건을 넣는 것과 돈을 받는 것은 **다른 사건**이다. 그 둘을
연결하는 것이 서류다. 서류가 하나라도 비면 그 물건은 공짜로 준 것이 된다.

| 서류 | 언제 | 무엇을 증명하나 |
|---|---|---|
| **거래명세서** | 납품·사용분 확정 | "이 병원에 이 물건이 이만큼 들어갔다" |
| **가납서** | 정식 발주 전 물건 선투입 | "정산은 나중에, 물건은 지금" |
| **선납서** | 환자별 사용분 발생 시 | "이 환자에게 이게 쓰였다" |
| **견적서** | 장비 제안·수리비 청구 | "이 값에 드리겠다" (1개월 유효) |
| **데모인수증** | 데모 장비 반출 | "빌려준 것이지 판 것이 아니다" |
| **세금계산서** | 월 마감 | 실제 청구 |
| **매출원장** | 월초 (하늘병원) | 한 달치 요약 |

### 가장 많이 나는 사고 세 가지

1. **매수 부족** — 다시 출력하러 나가야 한다. 반나절이 날아간다.
2. **도장 누락** — 서류 반려. 다음 달 마감으로 밀린다.
3. **선납서 분실** — 고대병원은 마감 자체를 안 도와준다.

---

## 2. 매수 — 병원별로 다르다

기본은 4장이지만, 예외가 절반이다.

| 매수 | 병원 |
|---:|---|
| 1장 | 신촌세브란스 (SSCM 사이트 출력) |
| 2장 | 서울의료원 (선납서) |
| 3장 | 서울아산, 청담리온, 혜민, 서울현대, 구리센트럴, **서울척**, 김앤조(VT band), 노원을지, 성남시의료원, 청담해리슨, 고대(선납서) |
| 4장 | 분당서울대, 서울점프, 연세무척나은, 하늘, 세종스포츠 |
| **5장** | **서울적십자** (가장 많음) |
| 0장 | 김앤조 — 플라이트 후드는 병원 서류 불필요 |

> **서울척병원만 3장이다.** 다른 곳처럼 4장 들고 가면 혼선이 생긴다.
> 반대로 서울적십자는 5장이라 4장만 들고 가면 한 부서가 빈다.

확인 안 된 곳: 서울대, 상계백, 호수병원. 기본 4장 준비하고 현장에서 확정한다.
`sumex audit` 로 언제든 확인 가능.

## 3. 도장 — 찍는 곳과 안 찍는 곳

| 구분 | 병원 | 내용 |
|---|---|---|
| **도장 3종** | 세종스포츠 | 수술실 · 재무팀 · 심사팀. **하나라도 빠지면 반려** |
| 도장 필요 | 서울아산, 서울척 | 검수·수술실 날인 |
| 도장 불필요 | 서울점프, 연세무척나은, 신촌세브란스, 서울의료원 | 제출만 하면 됨 |

세종스포츠와 서울점프를 헷갈려 도장 찾다 시간 낭비하는 일이 실제로 잦다.
**두 곳은 같은 광진구이고 같은 날 돌기 쉬운데 규칙이 정반대다.**

## 4. 병원별 절차 — 헷갈리기 쉬운 곳만

### 세종스포츠정형외과 — 가장 복잡

```
사용분 문자 수신
  → 담당 주임에게 전달 → 빠르게 팩스 회신   ("빠르게"를 병원이 강조함)
  → 거래명세서 4장 지참
  → 수술실에서 도장, 그 자리에서 1장 제출
  → 버거킹 옆 건물 3층으로 이동
      → 재무팀 도장 + 심사팀 도장 직접 날인
      → 재무팀함 1장, 심사팀함 1장 투입
  → 도장 다 찍힌 마지막 1장은 우리가 챙겨 온다
```

총무(재무팀)·심사팀이 **본원이 아니라는 것**이 핵심이다.

### 서울척병원 — 3장, 층 이동이 크다

```
간납사(지이아이글로벌) 사이트에서 환자별 거래명세서 출력 (3장)
  → 14층 수술실에서 도장, 1장 제출
  → 지하 2층 총무팀에 1장 제출
  → 1장 보관
```

수술실이 최상층(14층), 총무팀이 최하층(B2)이다. 시간 여유를 두고 간다.
주차장은 평일 17:00까지.

### 서울아산병원 — 창고를 두 번 간다

```
거래명세서 3장 출력
  → 지하 1층 관리부 맞은편 창고에서 검수
  → 서관 3층 수술방 옆 중앙창고에서 검수
  → 도장 수령
  → 다시 지하 1층 창고로 가서 거래명세서 제출
```

### 신촌세브란스 — 사이트 입력이 먼저다

```
SSCM (https://sscmx.yuhs.ac/m/login.ys) 에서 LOT No. + 유효기간 기입
  → 1장 출력
  → 1층 물품검수실 검수 → 스티커 부착
  → 5층 본관 수술방 납품
  → 모바일 검수도 SSCM 에서 함께 진행
```

주 1회 방문. **목요일은 자제 요청**받았다.

### 분당서울대(헬스케어혁신파크) — 시간이 전부

- 납품 가능: **09:00~11:00 / 13:00~16:00**
- 냉장·냉동 품목: **14:00 이전만**
- 장소: 헬스케어혁신파크 지하 (주차장 / 지하1층 관리팀 — 첫 방문 시 확정)
- 쇼핑백 말고 **흰색 봉투**에 넣어서 방문

시간대를 놓치면 그날 납품 자체가 불가능하다. 재방문이다.

### 서울적십자병원 — 5장, 응대 속도가 관건

```
병원 구매과에서 발주 메일 수신
  → 거래명세서 5장
      수술방 1 / 지하1층 물품관리실 1 / 4층 보험심사팀 1 / 총무팀 1 / 자사 1
```

이 병원은 **결론이 안 나도 중간 상황을 먼저 알려야** 하는 곳이다.
회신 지연 자체가 불만이 된다.

### 청담리온정형외과 — 환자 1명당 1장

수술방에서 사용분 사진을 카톡으로 보내준다. 그 사진을 근거로
**환자 한 명당 거래명세서 한 건**을 작성한다. 묶으면 안 된다.
서류 오류에 매우 민감한 병원이다.

### 구리센트럴병원 — 간납사를 한 번 거친다

```
아네스네트웍스에 '간납금액'으로 작성한 거래명세서 메일 발송
  → 아네스가 회신한 거래명세서 수령
  → 그 서류로 병원 납품 (수술방 1 / 총무과 1 / 자사 1)
```

우리가 만든 서류가 아니라 **간납사가 돌려준 서류**로 납품한다.

### 노원을지대학교병원 — 제출처가 두 곳

| 무엇 | 어디 |
|---|---|
| 세금계산서 · 데모 후 제출 서류 | 지하 관리팀 (을지의생명과학연구소) |
| 심사마감 서류 | 본관 밖 **별관** 건물 |

거래명세서는 간납사(토탈메디칼)가 병원 양식으로 작성해 준다.
제출 순서는 **토탈메디칼 → 수술방 → 심사과 → 토탈메디칼**.

### 고려대학교병원 (안암·안산·구로) — 마감이 가장 엄격

선납서 3부. 스마트엠 검수 → 수술방 검수 순서.

월 마감 때 **한 달치를 통째로** 들고 간다.

```
계산서 1부
+ 사이트에 업로드된 거래명세서 3부
+ 한 달 동안 납품한 선납서 전체
```

> ★ **거래명세서 수량 총합 == 선납서 수량 총합**
> 두 값이 같아야 마감이 통과된다. 서류가 미비하거나 선납서를 분실하면
> 마감을 도와주지 않는다. → **선납서는 발행 즉시 스캔해 둔다.**

구로·안암은 수술방 마감 시 **오후 4시 이전** 도착. 순서는 수술방 → 스마트엠.

## 5. 월 마감 캘린더

```bash
sumex month 2026-09      # 그 달 마감 일정 전체
sumex ics --month 2026-09  # 구글 캘린더로 가져오기
```

| 시점 | 무엇 |
|---|---|
| 매월 **1일** | 노원을지 — 토탈메디칼 사이트 접속해 이달 마감 기간 확인 (알림이 안 온다) |
| 매월 **1~3일** | 청담리온 — 이 기간을 넘기면 간납사에서 계속 전화가 온다 |
| 매월 **초** | 고대 — 간납사 사이트 마감 일정 공지 확인 |
| 매월 **초** | 세종스포츠 — 도장 받은 명세서 스캔본 + 간납금액 명세서 메일 |
| 매월 **초** | 하늘병원 — 구매과에 매출원장 전달 |
| 월 **2회** | 성남시의료원 — 파마블루가 보내주는 명세서 수령·배부 |
| 매월 **말** | 하늘병원 — 구매과와 일정 잡아 직접 방문 카드 수금 |

마감일을 놓치면 **대금 지급이 밀린다.** 이것이 서류 업무의 유일한 존재 이유다.

## 6. 연휴 앞

연휴 직전 영업일에 마감해야 할 것을 **반드시 그날 안에** 끝낸다.
`sumex today` 가 다음 영업일이 이틀 이상 뒤면 알아서 경고한다.

예: 2026-08-14(금) → 8/15 광복절, 8/17 대체공휴일 → 다음 영업일 8/18(화).
연휴 전에 납품·서류·세금계산서를 처리하지 않으면 3일이 통째로 빈다.

## 7. 서류 만들기

### 거래명세서 / 가납서 / 선납서

```bash
sumex doc 세종스포츠 --items "ICONIX 1.7T x 3 @ 320000; ICONIX 1 NEEDLES x 2 @ 33350" --suffix 수술방
```

- 생성 위치: `out/서류/SUMEX 거래명세서(...)_YYMMDD_수술방.xlsx`
- 파일명 규칙은 실제 사용 중인 것과 같다
- 금액은 **VAT 포함가**로 넣는다. 공급가액 = 합계/1.1, 부가세 = 합계 − 공급가액
- 만들고 나면 그 병원 체크리스트가 함께 출력된다

품목이 많으면 CSV 를 쓴다.

```csv
코드,상품명,포장단위,수량,단가
B3340006,Exofin HVTA bond,EA,30,63620
```

```bash
sumex doc 서울점프 --items items.csv
```

### 견적서

```yaml
# quote.yaml
subject: 1788 관절경 타워
groups:
  - group: 1788 VIDEO CAMERA SYSTEM
    items:
      - { code: 1788-010-000, name: 1788 Camera Control Unit, qty: 1, price: 0 }
  - group: LIGHT SOURCE
    items:
      - { code: 0220-230-300, name: Light Source L11, qty: 1, price: 0 }
```

```bash
sumex quote 호수병원 --spec quote.yaml
```

> 장비는 **낱개가 아니라 패키지로** 제안한다. 카메라만 넣고 소모품을 놓치면
> 타사 호환 상태가 되어 만족도가 떨어진다.

### 데모인수증

```yaml
# demo.yaml
hospital: 노원을지
dept: 정형외과
doctor: 홍길동 교수님
institution_no: "11101016"
address: "서울특별시 노원구 한글비석로 68"
release_date: 2026-09-01
items:
  - { model: 1788010000i, name: 1788 CAMERA CONTROL UNIT (CCU), qty: 1,
      license_no: 수신23-2838, category: 의료영상 처리장치, maker: "미국, Stryker Endoscopy" }
```

```bash
sumex demo demo.yaml
```

회수일은 기본 출고일 +30일. **회수 일정을 캘린더에 반드시 등록**한다.
빈 칸(요양기관번호·의사명·Serial/Lot)이 있으면 경고가 나온다.

데모인수증에서 놓치기 쉬운 것:
- 출고일 포함 **3일 안에** 제품·수량을 확인해야 한다. 3일 지나면 인수 완료 처리
- 대여 물품은 **한국스트라이커 자산**이다. 파손·분실 시 우리가 배상 책임
- 환자에게 사용해도 그 비용을 별도 청구할 수 없다
- 회수 주소: 서울 송파구 송파대로 55 A동 603-2호 스트라이커 CR팀

## 8. 간납사(도매상) 지도

간납사가 끼면 우리가 병원에 직접 청구하지 않는다. 서류 흐름이 한 단계 늘어난다.

| 간납사 | 병원 |
|---|---|
| 이지메디컴 | 서울대, 서울아산 |
| 메디굿파트너스 | 서울아산 |
| 에비슨케어 | 신촌세브란스 |
| 리노메디칼 | 상계백 |
| 비엔제이홀딩스 | 청담리온 |
| 윤찬 | 혜민 (**급여 제품에 한해서만**) |
| 아네스네트웍스 | 구리센트럴 |
| 스타메디홀딩스 | 세종스포츠 |
| 지이아이글로벌 | 서울척 |
| 엠피케이바이오솔루션 | 김앤조 |
| 토탈메디칼 | 노원을지 |
| 파마블루 | 성남시의료원 |
| 스마트엠 | 고대 (안암·안산·구로) |

직거래(간납사 없음): 분당서울대, 서울의료원, 서울점프, 연세무척나은,
서울현대, 하늘, 서울적십자, 청담해리슨

## 9. 아직 비어 있는 것

`sumex audit` 이 항상 최신 목록을 준다. 2026-08-23 기준 주요 결손:

- **서울대·상계백·호수병원** — 서류 매수 규칙 미확인
