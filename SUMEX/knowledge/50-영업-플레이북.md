# 영업 플레이북 — 지식을 매출로 바꾸는 법

---

## 1. 병원은 누가 결정하는가

의료기기 영업이 어려운 이유는 **사용자·결정자·지불자가 모두 다르기** 때문이다.
제품을 쓰는 사람은 집도의, 구매를 결정하는 곳은 구매팀·위원회, 실제 돈을 내는
곳은 건강보험공단과 환자다. 세 축을 모두 만족시켜야 계약이 성립한다.

| 이해관계자 | 관심사 | 영업 포인트 | 접점 빈도 |
|---|---|---|---|
| 집도의 (교수/과장) | 임상 결과, 수술 편의, 학술적 명성 | 임상 근거, 술기 지원, 학회 기회 | 최고 (매 케이스) |
| 수술실 간호팀 | 세트 구성, 멸균, 재고, 준비 시간 | 정확한 세트 리스트, 신속 대응, 교육 | 매우 높음 |
| 의공학팀 | 장비 안정성, 유지보수, 호환성 | 서비스 SLA, 백업 장비, 기술 문서 | 장비 도입 시 |
| 구매팀 | 가격, 계약 조건, 공급 안정성 | 견적 경쟁력, 납기 신뢰, **서류 정확성** | 계약 갱신 주기 |
| 보험심사팀 | 급여 기준, 청구 삭감 리스크 | 코드·상한금액 정보 제공 | 신제품 도입 시 |
| 병원 경영진 | 수익성, 브랜드, 환자 유치 | 로봇 등 차별화 자산 | 대형 캐피털 딜 |

> **신입이 가장 자주 하는 실수**: 집도의만 공략하는 것.
> 집도의가 "이거 쓸게요"라고 해도 구매팀이 코드 등재와 가격 협상을 마치지 않으면
> 한 개도 안 나간다. 반대로 구매 조건만 좋아도 집도의 손에 안 익으면 재주문이 없다.
> **세 축을 동시에 관리하는 것이 영업의 본질이다.**

## 2. 영업 프로세스 7단계

1. **계정 파악** — 수술 건수, 주력 술식, 현재 사용 브랜드, 계약 만료 시점
2. **진입 접점 확보** — 학회·심포지엄, 기존 고객 소개, 소모품 소량 트라이얼
3. **임상 근거 제시** — 논문·레지스트리 데이터·타 병원 레퍼런스
4. **트라이얼 케이스** — 실제 수술에서 써보게 하고 **반드시 현장에 입회**
5. **행정 절차** — 식약처 허가·보험 코드·상한금액 확인, 신규 품목 등재 신청
6. **가격/계약 협상** — 견적, 세트 구성, 위탁재고(consignment) 조건
7. **정착과 확장** — 재주문 관리, 다른 집도의로 확산, 인접 품목 교차판매

## 3. 케이스 커버 — 대리점 영업의 핵심 업무

제조사가 대리점에 기대하는 가장 중요한 가치이자, 신입이 가장 빨리 신뢰를
얻거나 잃는 순간이다.

| 시점 | 할 일 |
|---|---|
| **D-3** | 수술 스케줄 확인, 환자 상태·수술 종류 파악, 필요 세트와 사이즈 범위 예측 |
| **D-1** | 재고 확인 및 배송, 멸균 소요시간 역산, 백업 사이즈 확보, 간호팀과 세트 확인 |
| **당일 수술 전** | 장비 작동 점검(배터리·카메라·펌프), 세트 개봉 순서 확인 |
| **수술 중** | 다음 스텝 예측하여 미리 준비, 사이즈 변경 요청 즉시 대응, **절대 무균 영역 침범 금지** |
| **수술 후** | 사용 제품 기록 및 소모품 청구 자료 정리, 집도의 피드백 청취, 다음 케이스 예약 확인 |

### 케이스 커버 3원칙

1. **예측한다** — 요청받기 전에 준비한다
2. **침묵한다** — 수술 중 불필요한 말을 하지 않는다
3. **기록한다** — 사용 사이즈와 집도의 선호를 반드시 남긴다.
   **이 기록이 6개월 뒤 가장 강력한 무기가 된다**

준비는 7축으로: `sumex casecover <병원>`

## 5. 계정 유형별 공략 패턴

| 유형 | 특징 | 공략 순서 |
|---|---|---|
| 대학·상급종합 | 교수별 선호 강함, 절차 복잡, **레퍼런스 가치 큼** | 과별 키맨 → 데모 → 소량 트라이얼 → 정식 등재 |

| 공공·시립 | 입찰·규정 중심, 가격 민감 | **서류 정확성 + 납기 신뢰**가 승부 |

## 6. 개원 세팅 — 패키지로 가져오는 싸움

개원 세팅은 품목을 하나씩 넣는 싸움이 아니라 **"수술방 한 세트"를 통째로
가져오는 싸움**이다.

```
카메라(1788) + 펌프 + 셰이버·RF + 임플란트(VersiTomic·ICONIX)
```

를 묶어 제안하면 경쟁사가 중간에 끼어들 여지가 줄어든다. 반대로 카메라만 넣고
소모품을 놓치면 **"타사 호환" 상태**가 되어 만족도가 떨어진다.

### 관절경 개원 제안 우선순위

| 순위 | 제품군 | 왜 |
|---|---|---|
| 1 | 1788 4K 카메라 시스템 + 관절경 타워 | 카메라가 없으면 관절경 술기 자체가 불가. 가장 먼저 결정되는 품목 |
| 1 | 셰이버 / 버 / RF | 관절경 소모품의 축. 카메라와 세트로 움직인다 |
| 1 | Fluid Management (관절경 펌프) | 카메라·셰이버와 함께 관절경 3종 세트 |
| 2 | VersiTomic / ProCinch | ACL·PCL 재건, 반월상연골 근위부 봉합 |
| 2 | ICONIX (Knotless / HA+) | 어깨·고관절 관절와순 봉합 |
| 3 | AlphaVent | 하드바디 앵커 — 타입 2종 동시 제안으로 '손맛' 이탈 위험 낮춤 |

### 렌트(대여) 조건 제안 시 주의

개원 초기에는 자금 부담이 커서 렌트가 유효한 카드가 된다. 다만 **서울척병원
사례처럼 집도의가 바뀌거나 제품이 손에 안 맞으면 렌트 재고를 통째로 회수해야
한다.** 렌트 조건을 제안할 때는 **최소 사용 물량과 회수 조건을 문서로 남기고**
회사와 사전 협의한다.

## 7. 계정을 잃는 법 — 서울척병원 사례

월 매출 약 700만원 규모의 계정에서 **집도의가 바뀌자 ICONIX 사용이 중단됐다.**
2026-08-14 회수를 진행하고 세팅을 5개로 축소했다.

사용 중단 사유로 세 가지가 언급됐다.

1. 앵커는 '손맛'이 있어 집도의 손에 안 맞으면 못 쓴다
2. 고정력 불만
3. 적응증 케이스 자체가 없다

**실제 사유가 무엇인지 확정해야 대응이 가능하다.**

| 실제 사유 | 대응 |
|---|---|
| 손맛 | 다른 규격·타입 제안 (AlphaVent 등 하드바디 병행) |
| 고정력 | 스트라이커에 기술 자료·임상 데이터 요청 |
| 케이스 부재 | 시간을 두고 기다린다. 무리하면 관계만 상한다 |

### 이 사례에서 배울 것

- **관계 자산이 사람에 붙어 있으면 사람이 떠날 때 같이 간다.**
  병원 처우가 나빠 의사 이직이 잦은 곳은 구조적으로 위험한 계정이다.
- 앵커는 처음부터 **타입을 두 가지로** 제안해 이탈 위험을 낮춘다.
- 회수품은 개봉 이력이 있으면 타 병원에서 받지 않아 재사용이 어렵다.
  **회수 방침을 미리 회사와 정해 둔다.**
- 매출 확대 vs 최소 관리는 담당자 선에서 결정할 사안이 아니다. **경영진에 보고한다.**

## 8. 계정을 얻는 법 — 호수병원 사례

2026-09-01 개원 예정 병원. 왜 최우선 신규 기회인가.

- 76병상 / 직원 60명 / 전문의 5명(정형 2·신경외과 1·내과 1·영상 1)
- **수술실 스크럽 간호사 채용 중** + 마취통증의학과 보유 = 수술하는 병원 확정
- 공동대표가 서울척병원 관절센터 출신 (무릎 인공관절·관절경·ACL 재건)
- **이미 우리 제품을 써본 분이고 관계도 있다**

**타이밍이 전부다.** 개원 전인 지금이 장비·소모품 벤더가 결정되는 시점이다.
채용공고가 실시간으로 수정되고 있다면 세팅이 진행 중이라는 뜻이다.
개원 후에는 늦다.

**레퍼런스를 화법으로 쓴다**: "같은 장비로 이 지역 어깨 전문의도 만족하셨습니다."
을지병원 참관에서 1788 화질 만족도가 높았다면 그것이 바로 근거다.

## 9. 장비 수리 지연 대응 — 중간에서 압박받지 않는 법

병원은 "빨리 고쳐달라", 본사는 "장비·부품이 없다". 영업 담당이 중간에서
압박받는 구조다.

1. **병원에 완료 날짜를 먼저 약속하지 않는다.**
   "접수하고 예상 일정 확인해서 바로 회신드리겠습니다"로 일단 끊는다.
   날짜를 말하는 순간 책임이 넘어온다.
2. **접수 시 세 가지를 함께 확인한다** — ①예상 소요 기간 ②부품 재고 유무
   ③**대체 장비(loaner) 대여 가능 여부**
3. **대체 장비 대여 여부를 매번 확인한다.**
   병원이 화내는 실제 이유는 수리 지연이 아니라 **수술 일정이 밀리는 것**이다.
4. **진행 상황은 병원이 묻기 전에 먼저 연락한다.**
   지연 자체보다 '연락이 없는 것'에 불만이 쌓인다.
5. **대장으로 관리한다** — 접수일 / 병원 / 증상 / 회신 / 예상 완료일 / 실제 완료일.
   책임 소재가 명확해지고, 반복 시 본사 개선 요청 근거가 된다.

```bash
sumex repair open 서울적십자 "1788 CCU" "전원이 간헐적으로 꺼짐"
sumex repair update --id R26-001 --set status=본사확인중 vendor_reply="부품 재고 확인 중" eta=2026-09-05
sumex repair list --open-only
```

`sumex today` 가 회신 없이 3일 이상 지난 건을 알려준다.

## 10. 가격과 수익 구조

```
제조사(Stryker) → 수입/총판 → SUMEX(대리점) → 병원 → 건강보험공단·환자
```

대리점 마진은 병원 판매가와 매입가의 차이다. 여기서 재고 보유비용, 케이스 커버
인건비, 물류비, 대금 회수 리스크를 부담한다.

| 비용 항목 | 관리 포인트 |
|---|---|
| 재고 부담 | 회전율 낮은 SKU 최소화, 위탁 조건 협상 |
| 케이스 커버 인건비 | 고단가 케이스 우선 배치 |
| 멸균·물류 | 권역별 재고 거점 |
| **미회수·반품** | **사용 후 청구 누락 = 매출 누락.** 사용 기록 즉시 전산화 |
| 상한금액 인하 | 고시 모니터링, 품목 믹스 조정 |

### 급여와 상한금액

치료재료는 「치료재료 급여·비급여 목록 및 급여상한금액표」(복지부 고시)에
등재되어야 보험 적용을 받는다. **상한금액이 사실상 판매가 상한이다.**

습관화해야 할 두 가지:

1. 신제품 제안 **전에** 보험 코드와 상한금액이 존재하는지 먼저 확인한다
2. 고시 개정을 정기적으로 모니터링한다 — 인하되면 그날부로 마진이 줄어든다

## 11. 컴플라이언스

**위반 시 형사처벌과 판매업무정지로 직결된다.**

| 규제 | 실무 원칙 |
|---|---|
| 의료기기법 리베이트 쌍벌제 | 현금·상품권·향응·과도한 편의 제공 **전면 금지**. 제공자·수수자 모두 처벌 |
| 경제적 이익 지출보고서 | 견본품, 학술대회 지원 등 **모든 내역 기록** |
| 청탁금지법 | 국공립 의료기관 종사자 등 금품·향응 제한. 식사·선물 한도 준수 |
| 공정경쟁규약 | 학술대회 지원·제품설명회는 **반드시 회사 승인 절차 후** 집행 |
| 개인정보·환자정보 | 수술실에서 취득한 환자 정보 **촬영·유출 절대 금지** |
| 감염관리 | 수술실 출입 절차, 무균 영역. 병원 규정 준수 |

데모인수증에 기재된 사항은 의료기기법에 따라 **지출보고서에 포함되어 공개되거나
심평원 등에 제출될 수 있다.** 데모 서류를 대충 쓰면 안 되는 이유다.

> **판단 기준 한 줄**: "이 행위가 내일 신문에 나도 설명할 수 있는가?"
> 조금이라도 망설여지면 하지 않는다. 그리고 반드시 상급자에게 먼저 묻는다.
